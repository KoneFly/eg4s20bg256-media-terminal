# 主板操作对照表（本版 实物按键映射修正）

> 2026-11-03 按冻结RTL及实物球脚核对。当前位流：包内 `bit/master_f35.bit`；工具通过，待实板。原本版操作表作为历史保留，本表适用默认静音与完整软重启版本。
> 实物球脚：KEY1=A2，KEY2=B2，KEY3=B1，KEY4=C1。本版～本版曾把KEY3/KEY4对调；用户已实证本版长按实物KEY4可恢复。本版恢复与主线C01相同的对应。
> 应用场景：**车载多媒体终端**（简介末句"设备噪声治理、展陈与巡检"为同类延伸）。
> 拨码"拨上 = 开"。**页面优先级：SW1 > SW3 > SW2 > 图片页（全关）**。KEY1 = 全局复位。
> 长按需超过1秒，演示建议持续按住约2秒；按住期间切换拨码，该次按键作废。

## 0. SW 页面选择与准备

| 拨码状态 | 页面/作用 | 演示时的其他拨码 |
|---|---|---|
| SW1～SW4 全关 | 图片全屏/图墙 | — |
| SW1 开 | 设置菜单叠加；媒体继续运行 | SW2/SW3 可保持当前媒体选择 |
| SW2 开 | 音乐播放器与曲目控制 | SW1、SW3 关 |
| SW3 开 | 视频播放与换片 | SW1 关；SW3 优先于 SW2 |
| SW4 | 当前无功能 | 演示保持关 |

演示用 TF 根目录放 `PIC1.BMP`～`PIC8.BMP`（建议连续齐全）、`WAV1.WAV`～`WAV4.WAV`、`VID00000.V29` 起的视频文件；启动动画另放根目录 `BOOT.V29`。不要只把整个素材文件夹复制到卡上。

文件口径：图片为 24 位未压缩 BMP；音乐为 PCM 16 位、单声道、48 kHz WAV；视频为已转换的 640×480 V29，MP4 是 PC 预览文件。V6 根目录提供普通媒体；`boot_assets/BOOT.V29` 需要另复制到 TF 根目录，配正常 PIC1。

主板单独即可演示图片、视频、WAV 与 HDMI 声音；外放及 PLAY/PLAY-RAW 两种频谱都需要兼容副板与相应链路，双谱还需副板返回现场麦克风一路。主板菜单不替代副板自身的外放、采集、ANC 等控制。

## 1. 按键总表

实物按键：KEY2=B2，KEY3=B1，KEY4=C1。KEY3/KEY4全部短按、长按动作均按此对应。

| 按键 | 图片页（拨码全关） | SW2 音乐页 | SW3 视频页 | SW1 设置页 |
|---|---|---|---|---|
| **KEY1** | 全局复位、恢复默认、重新判断启动动画 | 同左 | 同左 | 同左 |
| **K2 短按** | 下一张（图墙中：焦点下一格） | 播放 / 停止（与设置页 MUSIC 同一开关） | 播放 / 暂停 | 下一项 |
| **K3 短按** | 上一张（图墙中：焦点上一格） | 下一首 | 下一个视频 | 当前项 − |
| **K4 短按** | 三级缩放 ÷1 → ÷2 → ÷4（全屏时） | 上一首 | 上一个视频 | 当前项 + |
| **K2 长按** | 全屏 ⇄ 八槽图墙 | — | — | 上一项 |
| **K3 长按** | 换卡完整重启 | 换卡完整重启 | 换卡完整重启 | 全部恢复默认 |
| **K4 长按** | — | — | — | — |

- SW4：无功能。
- SW2 音乐页显示**音乐播放器界面**（见 §5）；离开 SW2 回到原页面，音乐按 MUSIC 设置继续。
- 设置页叠加在当前画面上，媒体照常运行；关闭 SW1 后设置保留。
- SW2 只管曲目与停止；关闭 SW2 **不会**停止音乐。音乐开关以设置页 MUSIC 为准，SW2 页 K2 与 MUSIC 是同一个开关。
- 图墙共 8 槽，分成 1～4、5～8 两组，每屏显示 4 张。K2/K3 移动焦点并跨组，K2 长按打开焦点图；K4 在图墙中不切换缩放。
- 全屏 K4 的三级档位为等效采样 640×480 / 320×240 / 160×120，画面铺满显示区域，HDMI 输出时序始终为 640×480。换图或进入图墙会回到 ÷1。
- 菜单参数仅在本次运行中保留，KEY1/重新上电及媒体页KEY3完整重启恢复默认。K3 在菜单长按是恢复默认，在媒体页长按才是完整重启读卡。

## 2. 设置页（SW1）

| 项 | 选项 | 上电默认 | 说明 |
|---|---|---|---|
| MUSIC | OFF / ON | OFF | ON：播放 TF 卡 WAV（图片页、音乐页、设置页都在后台播放）；OFF：停止背景音乐并输出静音；视频伴音按视频播放状态控制 |
| VOLUME | 0 – 20 | 20 | HDMI 与副板外放同一路 |
| TRANSITION | OFF / FADE / WIPE / CURTAIN / AUTO | OFF | AUTO = 淡入淡出→擦除→幕布轮换；OFF = 整帧直切 |
| PERIOD | OFF / 1 – 60 S | 3 S | 自动轮播周期；OFF = 关闭自动轮播 |
| SPECTRUM | OFF / PLAY / PLAY-RAW | OFF | PLAY：回放渐变音柱；PLAY-RAW：回放音柱 + 现场麦克风填充波形；两档都需副板回传有效频谱 |
| INFO | OFF / ON | OFF | ON：顶部单行跑马灯仪表盘 |
| OUTPUT | HDMI+SPK / SPK ONLY | HDMI+SPK | SPK ONLY：HDMI 静音，副板外放与频谱照常；只要 HDMI 时用副板外放开关 |

上电默认即**赛题基础形态**：整帧直切 + 3 s 自动轮播 + 静音，无任何叠加层；扩展功能进设置页逐项打开。

操作规则：K2 短按选择下一项，长按上一项；K3 短按减、K4 短按加。MUSIC/INFO 的 K3 为 OFF、K4 为 ON；OUTPUT 的 K3 为 HDMI+SPK、K4 为 SPK ONLY。TRANSITION/SPECTRUM 循环选择，VOLUME/PERIOD 到上下限停住。长按 K3 恢复全部默认并回到 MUSIC 项；K4 长按没有连加功能。

## 2.1 上电启动动画

| 情况 | 行为 |
|---|---|
| 卡根有 `BOOT.V29`，上电在图片页 | 先把 PIC1 读进图片页但不显示，再播一遍启动动画（不循环），末帧在帧边界直接换成 PIC1，中间无黑帧 |
| 动画播放中短按 K2/K3/K4 | 请求跳过并切到 PIC1；推荐 K2，这次翻页事件被消费，不会顺带翻到 PIC2。KEY1 始终是复位，不是跳过 |
| 无 `BOOT.V29`、文件头不合法、2 秒内一帧都没上屏 | 直接显示 PIC1，不卡黑屏 |
| 上电时就在 SW3 视频页 | 不播动画，直接进视频 |
| 动画期间 | 菜单、仪表盘、播放器、频谱都不叠加；交接后恢复实际设置 |
| KEY1 全局复位 | 重新走启动判断（再播一次）；K3 在媒体页长按也执行完整重启，按上电规则处理 BOOT |
| 交接后 | PIC1 轮播计时从交接时重新起算 |

无缝衔接要求动画最后一帧与 PIC1 在 RGB565 域逐像素相同（V6 素材 `boot_assets/BOOT.V29` 已满足，配正常 PIC1；RGB332 版必须同时换用 `PIC1_332_MATCH.BMP` 作为 PIC1）。

## 3. 媒体与声音规则

| 情况 | 画面 | HDMI / 外放声音 |
|---|---|---|
| 图片页，MUSIC=OFF | 图片 | 静音 |
| 图片页 / 音乐页 / 设置页，MUSIC=ON | 图片 | WAV 音乐（换大图时可能顿 0.1–0.2 s，上电后台读缩略图期间亦可能断续） |
| SW3 视频页 | 视频 | 视频伴音优先；音乐自动暂停 |
| 退出视频页 | 回到原图片 | 音乐恢复（MUSIC=ON 时）；缓冲清尾会略过少量样本，不作为精确断点续播演示 |

- 视频文件：`VID00000.V29` … `VID00009.V29`（最多 10 个，缺号自动跳过、首尾循环）。
- 音乐文件：`WAV1.WAV` … `WAV4.WAV`（缺号跳过、首尾循环）。
- 图片文件：`PIC1.BMP` … `PIC8.BMP`。上电先显示 PIC1 大图，其余后台加载；图墙按组（1–4 / 5–8）整组就绪才进入。

## 4. 仪表盘（INFO=ON）

顶部一行半透明横条，字段串从右向左循环滚动，例如：

```
VIDEO  RES 640X480 FPS 30 RGB332 TIME 00:04 PLAY
PHOTO  PIC 2/8 SRC 1920X1080 OUT 640X480 MUSIC WAV1
```

`OUT` 随三级缩放显示 640X480 / 320X240 / 160X120。

## 5. 音乐播放器界面（SW2 页）

```
┌──────────────────────────────────────────────┐
│  (背景: 当前图片原样显示, 不自动轮播)           │
│                              MUSIC WAV2/4    │
│                              PLAY  01:23/03:40│
│                              ━━━━━━━━──────── │
│                                              │
│  ▁▃▅▇▅▃▂▁▃▅▇█▇▅▃▁  频谱(按 SPECTRUM 设置)      │
└──────────────────────────────────────────────┘
```

- 只显示曲目、播放状态与时间（已播放/总长）、进度条。
- **切歌同时换背景图**：K3 下一首 → 下一张图，K4 上一首 → 上一张图；曲尾自动下一首时也换下一张。缺号图片自动跳过。
- 输出切换见设置页 OUTPUT 项。
- 频谱在 SPECTRUM 设置中开启：音柱偏黄/橙/红，现场声波形偏青/蓝/紫；颜色沿高度和频段变化，波形半透明，重叠处音柱也混色；时间与邻近频段平滑自动生效，没有另设滤波按键。

## 6. 全功能演示顺序

下表 K2/K3/K4 未注明“长按”时均为短按。进入设置后用 K2 选择目标项，再按 K3/K4 调值；菜单焦点会保留，不假设每次打开都在 MUSIC。

| 顺序 | 功能 | SW / KEY 操作 | 预期观察 |
|---|---|---|---|
| 1 | 自动启动与首图 | TF 已放 BOOT 和 PIC1；SW 全关，按 KEY1 | 动画播放后进入 PIC1 大图；其他缩略图后台加载，启动期间不叠菜单、仪表盘和频谱 |
| 2 | 跳过启动 | 再按 KEY1；动画中短按 K2 | 回到 PIC1，本次按键不顺带翻到 PIC2 |
| 3 | 默认轮播与静音 | SW 全关，不操作 | 默认约 3 s 停留后切换图片；转场关闭，听到静音 |
| 4 | 手动翻图 | SW1 开：PERIOD 设 OFF、INFO 设 ON；SW1 关；K2 下一张、K3 上一张 | 手动切图，顶部显示图片编号、源尺寸和采样档位 |
| 5 | 不同尺寸图片适配 | 在图片页用 K2/K3 到 V6 的 PIC2、PIC8 | 1920×1080、800×1200 图片适配到固定画面；无需另选加载模式 |
| 6 | 三种转场 | SW1 中依次选 FADE、WIPE、CURTAIN；每次关闭 SW1 后按 K2 | 分别显示淡入淡出、擦除、幕布；回 OFF 为直切 |
| 7 | 自动转场轮播 | SW1：TRANSITION=AUTO、PERIOD=5S；SW1 关 | 周期轮播，三种转场轮换；演示结束把 PERIOD 改回 OFF，便于图墙/缩放演示 |
| 8 | 八槽图墙 | 图片页长按 K2；K2/K3 移焦点，跨第 4/5 张切换组；再次长按 K2 | 每组 4 张缩略图和焦点框；打开选中图片。首次进入可能等待本组缩略图准备完成 |
| 9 | 三级采样切换 | 全屏图片状态连续短按 K4 三次 | ÷2→÷4→÷1；INFO 的 OUT 字段对应变化，HDMI 始终输出 640×480 |
| 10 | 背景音乐 | SW1：MUSIC=ON；SW1 关；K2/K3 翻图 | 图片操作时继续播放音乐；读图过程中可观察声音连续性 |
| 11 | 音乐播放器与图曲联动 | SW1/SW3 关、SW2 开；K3 下一首、K4 上一首；K2 停止，再按 K2 播放；关闭 SW2 | 曲目、已播/总时长、进度条；切歌带动换图。关闭 SW2 后 MUSIC=ON 则音乐继续；停止音乐会回到静音 |
| 12 | 单谱与双谱 | 副板已正常回谱；SW1：SPECTRUM=PLAY，再设 PLAY-RAW；关闭 SW1；对麦克风说话或轻拍 | PLAY 是回放音柱；PLAY-RAW 增加现场声填充波形，观察横纵渐变、重叠混色与平滑 |
| 13 | 音量与静音 | SW1：VOLUME 用 K3 降、K4 升，降到 0 后恢复合适档位 | 回放音量变化；VOLUME=0 使回放静音；MUSIC=OFF 停止背景音乐后同样静音，视频伴音仍由视频模式控制 |
| 14 | HDMI / 扬声器输出 | 副板外放已开启；SW1：OUTPUT 按 K4 到 SPK ONLY，再按 K3 回 HDMI+SPK | 前者 HDMI 静音、扬声器继续；后者两路恢复。只听 HDMI 时在副板自身关闭外放 |
| 15 | 视频、暂停与换片 | SW1 关、SW2 关、SW3 开；K2 暂停/恢复，K3 下一片、K4 上一片 | 视频及伴音播放，暂停时画面冻结；INFO=ON 可见 640×480、FPS、RGB332/RGB565 和播放时间。视频接管音频，关闭 SW3 后回图片并恢复音乐 |
| 16 | 仪表盘开关 | SW1：INFO 用 K3 设 OFF、K4 设 ON；关闭 SW1 | 顶部跑马灯隐藏/显示；不用 SW4 |
| 17 | TF 热重载 | 回图片页且 SW1 关，插好换用的 TF，长按 K3 | 完整软重启后重新读卡；图片页按正常上电流程显示启动片或PIC1；菜单恢复默认、MUSIC关闭 |
| 18 | 恢复默认 | SW1 开，长按 K3，再关闭 SW1 | MUSIC/OFF、TRANSITION/OFF、PERIOD/3S、SPECTRUM/OFF、INFO/OFF、VOLUME/20、OUTPUT/HDMI+SPK；此操作不重新播放 BOOT |

可选恢复演示：用不含 BOOT 的卡按 KEY1，直接进入 PIC1；未插卡启动后插入有效卡，观察初始化重试，必要时在媒体页长按 K3 重载。

PIC1 的四栏首页属于图片素材，真正可调整参数的设置菜单由 SW1 打开。本版 已去除 SLIDE、UP 运行时间、播放器封面窗口/虚化背景及其额外音量/输出文字；当前操作以本表和PROGRESS最新位流登记为准。

## 7. LED含义

| 实物LED | 球脚 | 当前RTL含义 |
|---|---|---|
| LED1 | A4 | 当前资源优化版为纯心跳；链路故障看LED4及实际频谱 |
| LED2 | A3 | SD已进入高速模式，且SDRAM初始化完成 |
| LED3 | C10 | 图片提交状态；视频模式下为视频文件头有效状态 |
| LED4 | B12 | 媒体/显示/链路/音频欠载等综合错误，部分子项锁存至复位 |

LED2在25MHz兼容模式下可以熄灭，不能仅据此判卡故障；LED3不等同于“正在出声”。历史顶层长注释曾把LED2/LED3含义写反，本表按实际assign表达式核对。
