# F3 上板指南（主板 `release/f3/t073_f3_trial.bit`，SRAM 试位）

> 操作口径以 `CONTROL_MAP_F3.md` 为准；SHA 与数字见 `PROGRESS.md`。本版–本版 指南中的按键说明不再适用。
> 卡根目录：`BOOT.V29`（可选）、`PIC1..8.BMP`、`VID00000..VID00009.V29`（缺号可）、`WAV1..4.WAV`（缺号可）。

## 1. 上电与基础形态（拨码全关，不进设置）

| 步骤 | 操作 | 应看到/听到 |
|---|---|---|
| S1 | 上电（卡上有 BOOT.V29） | 播放一遍启动动画，末帧无黑屏直接切到 PIC1；播放中按任意键可跳过 |
| S2 | 卡上无 BOOT.V29 | 直接出 PIC1 |
| S3 | 观察 | 无任何文字/频谱叠加；测试音；3 秒自动轮播、整帧直切 |
| S4 | K2 / K3 短按 | 下一张 / 上一张 |

## 2. 设置页（SW1 拨上，媒体继续）

| 步骤 | 操作 | 应看到 |
|---|---|---|
| M1 | 拨 SW1 | 左上 SETTINGS 面板 7 项，当前项黄字 `< >` |
| M2 | K2 短 / K2 长 | 下一项 / 上一项 |
| M3 | K3 短 / K4 短 | 当前项减 / 加 |
| M4 | TRANSITION 选 AUTO，PERIOD 调 OFF 再调回 | 翻页出现转场；OFF 时停止自动轮播 |
| M5 | INFO ON | 顶部一行横条从右向左滚动，含 `UP hh:mm:ss` 上电运行时间 |
| M6 | SPECTRUM PLAY / PLAY-RAW（副板在线） | 下方黄→红渐变音柱；PLAY-RAW 再叠青→蓝半透明填充波形 |
| M7 | OUTPUT SPK ONLY | HDMI 静音，副板外放照常 |
| M8 | K3 长按 | 全部恢复默认 |
| M9 | MUSIC ON，然后拨下 SW1 | 测试音换成 WAV 音乐，并在图片页后台持续播放 |

## 3. 音乐与图片并行

| 步骤 | 操作 | 应看到/听到 |
|---|---|---|
| A1 | MUSIC ON 时翻页 | 音乐不断；换大图（如 1920×1080）时可能顿约 0.1–0.2 s |
| A2 | 拨 SW2 | 音乐播放器：当前图作封面（左）、背景虚化变暗；右侧曲目、状态、时间/总长、进度条、输出、音量 |
| A3 | SW2 页 K3 / K4 | 下一首 / 上一首（缺号跳过） |
| A4 | SW2 页 K2 | 停止（设置页 MUSIC 同步变 OFF），再按继续播放 |
| A5 | 拨下 SW2 | 回到原图片页，音乐不停 |

## 4. 视频（SW3）

| 步骤 | 操作 | 应看到/听到 |
|---|---|---|
| V1 | 拨 SW3 | 视频 + 伴音；音乐自动暂停让位 |
| V2 | K2 | 暂停 / 继续（画面定格、静音） |
| V3 | K3 / K4 | 下一个 / 上一个视频（缺号跳过） |
| V4 | 拨下 SW3 | 回到原图片；MUSIC ON 时音乐从暂停处稍后位置续播 |

## 5. 图墙、缩放、重载

| 步骤 | 操作 | 应看到 |
|---|---|---|
| W1 | 图片页 K2 长按 | 2×2 图墙（黄框焦点），K2/K3 移动焦点，跨组换页 |
| W2 | 图墙中 K2 长按 | 回全屏显示焦点图 |
| W3 | 全屏 K4 短按 | 三级缩放 ÷1 → ÷2 → ÷4 → ÷1 |
| W4 | 任意媒体页 K3 长按 | 换卡重载，回到 PIC1 |

请回报：每项是否符合；启动动画衔接是否看得出切换；音乐在换图时的停顿程度；播放器页与跑马灯的观感。
