# 第一部分 · v1 冻结设计（原 `音频采集板要求.md`）

# 音频采集中继板需求（四路 I2S 数字麦克风）

> 更新 2026-10-14 ｜ 形态 = **四路 I2S 麦克风中继板**（**直接插到主板「连接器 J1」**）
> 状态：**供画中继板使用**；标【待确认】的项需先定值再落版。

---

## 1. 本方案内容

- 只做**一块四路中继板**：**1 个 2×20 母座插到「连接器 J1」** + **4 个 `INMP441` 模块座** + 去耦 + `SD` 下拉。
- **不画麦克风芯片板** —— 不做裸芯片贴装、不做模拟前端、不做板上声学开孔（进音由模块自身决定）。
- **不放任何 codec / DAC 芯片。**
- **输出侧不在本板**：扬声器现有 FPGA 板上已有，见 §8。
- 合规口径：麦克风属**传感器**；

---

## 2. 器件（**已定：`INMP441` 模块**）

| 项 | 手册值 | 对我们的意义 |
|---|---|---|
| 接口 | **24 bit 标准 I²S** | 直接进 FPGA，无需解调 |
| **供电** | **1.62 ~ 3.63 V** | **3.3 V 直供，免 LDO** |
| 电流 | 2.2 mA @3.3 V | 4 颗约 9 mA、8 颗约 18 mA |
| SNR / 灵敏度 | 61 dBA / −26 dBFS | 优于片内 ADC 的 8 bit |
| **`SCK` 频率** | **0.5 ~ 3.2 MHz** | 3.07~3.13 MHz（48 k×64）**已用掉上限的 96~98%** ⇒ 时钟质量必须保证（见 §4-C2） |
| **`WS` 频率** | **7.8 ~ 50 kHz** | 48 kHz 在范围内 |
| 数字电平 | V_IH ≥ 0.7×V_DD、V_IL ≤ 0.25×V_DD | 3.3 V 下与 J1 **直连兼容** |
| **群延迟** | **359 µs @48 kHz** | 频谱分析无所谓；**做 ANC / 音画同步须计入** |
| 数字滤波 | 内置高通 + 低通 | Q4 现场采集用；**内置滤波不构成"算法外包"**（见 §1 合规口径） |
| 进音 | **底部进音**（4.72×3.76×1 mm） | **⇒ 进音面朝向必须在装配时确认，见 §4-E1** |

**模块引出 6 脚**：`VDD` / `GND` / `SCK` / `WS` / `SD` / `L/R`（**`CHIPEN` 未引出，应为模块内部已使能** —— 见 §10）。

**`L/R` 接法**：本方案各麦**独占一根 `SD`** ⇒ **`L/R` 一律接 GND**（占左时隙），FPGA 只读左时隙。

**为什么不"一左一右"**：`L/R` 只决定"数据在 I2S 帧的**哪个半周期**推上线"，**不产生立体声**（INMP441 是单声道麦）。一左一右**唯一的作用是让两颗麦共用一根 `SD` 线（省线）**；各自独占 `SD` 时，左右只是换个时隙，**数据完全一样、效果不会更好**。J1 有 36 路而本板只用 9 个，**不缺线 ⇒ 不为省 2 根线引入分时解复用的复杂度**。

---

## 3. 接口与连线

**模块脚名对照**：模块的 `SCK` = 我们的 **`BCLK`**（位时钟）；`WS` = **`LRCK`**（帧时钟）；`SD` = 数据；`L/R` **接 GND**。**接 J1 的脚位见 §12.2。**

```text
FPGA --BCLK(位时钟)--+----+----+----+    两线共享
FPGA --LRCK(帧时钟)--+----+----+----+
                     |    |    |    |
                   [麦1][麦2][麦3][麦4]
                     |    |    |    |
FPGA <--SD0----------+    |    |    |    各麦各自一根数据线
FPGA <--SD1---------------+    |    |
FPGA <--SD2--------------------+    |
FPGA <--SD3-------------------------+
```

各麦共享同一对 `BCLK`/`LRCK` ⇒ **同一时刻采样，是真正的同时采样**。

**【必办】每根 `SD` 必须对地下拉**：麦在不驱动的那半周期 `SD` **呈高阻 ⇒ 线浮空**，会造成不确定读数与输入缓冲额外翻转电流。**中继板上给每根 `SD` 加 `100 kΩ` 对地下拉**（或改由 FPGA 内部弱下拉，二选一）。同时 **FPGA 侧只在左时隙采样**。

## 4. 中继板设计要求（**重点**）

### A. 电气安全

| # | 事项 |
|---|---|
| **A1【致命】** | **照实物缺口核对第一脚方向** —— 手册原文：**J1 第一脚在正方向左上**（J2 在**右下**，两口相反）。**插反 = 5 V / 3.3 V 灌进 IO ⇒ 可能烧 FPGA** |
| **A2【致命】** | **脚 11 是 5 V，一个 IO 都不许接**；取电只能用**脚 29（3.3 V）**。即使模块标注可用 5 V，**也只用 3.3 V** |
| **A3【致命】** | **模块座方向不能反** —— 模块丝印为 `GND VDD SD`（上排）/ `L/R WS SCK`（下排）；**座子接反 = VDD/GND 对调 ⇒ 烧模块**。逐块照丝印核 |
| A4 | **不要带电插拔**（J1 无保护电路） |

### C. 信号完整性

| # | 事项 |
|---|---|
| **C1** | **每根 `SD` 加 100 kΩ 下拉**（见 §3） |
| **C2【注意】** | **`BCLK` 余量极小**（3.07~3.13 MHz vs 手册上限 3.2 MHz）⇒ **源端串 22~33 Ω**、避免长支线、**不与 `SD` 长距离并行** |
| C3 | **回流路径连续**：不在 `BCLK`/`SD` 下方开槽；保留**完整地平面** |
| C4 | **不需要等长** —— 3 MHz 在板级属低频段，走线差折算到时间是亚纳秒量级，抠等长是白费功夫 |

### D. 电源与去耦

| # | 事项 |
|---|---|
| D1 | **每颗麦 `100 nF` 紧靠 `VDD`**（位置比容值重要）；中继板另加 **1 颗 `10 µF`** 作板级储能 |
| D2 | **3.3 V 电流要实测**：4 路约 9 mA、8 路约 18 mA；**手册未给脚 29 的电流指标** ⇒ 首次上电测该脚电压跌落【待确认】 |
| D3 | **J1 只有 2 个 GND（脚 12、30）** ⇒ 4~8 颗麦的回流都挤这两个脚。**可选**：在中继板上把若干空闲脚并联接 GND 增加回流 —— 但**那样 FPGA 侧这些脚必须保持未使用、不得被固件驱动**（须与固件方约定） |

### E. 声学与机械

| # | 事项 |
|---|---|
| **E1【致命】** | **先肉眼确认模块的进音面** —— INMP441 是**底部进音**（声音从芯片**背面**进）。若模块把芯片贴在板正面，则**进音孔在模块朝下那一面** ⇒ **中继板对应位置必须开孔、或让模块与中继板之间留出空腔**，否则**进音被堵、灵敏度骤降** |
| E2 | **四颗朝向一致**（不一致会造成通道间幅相差异） |
| E3 | **别把进音面贴死在桌面/机箱上**，留出进音空间 |
| E4 | **排针受力**：中继板靠 J1 一排针悬空支撑 ⇒ 建议加**支撑柱/定位孔**或控制悬臂长度，别让模块重量全压在排针上 |
| E5 | **模块间距**：留出各自进音空腔，不互相遮挡 |

### F. 可测性与可扩展

| # | 事项 |
|---|---|
| F1 | **留测试点**：`BCLK`、`LRCK`、**每根 `SD`** 各留一个测试焊盘（调试必用示波器/逻辑分析仪） |
| F2 | **一并引出 8 路**：SD4~SD7 = 脚 **21（G16）/ 23（K15）/ 25（H15）/ 27（K16）**，与备用 GND 一起引到排针 ⇒ 以后扩 8 路不用重画 |
| F3 | **丝印**：每个模块座旁标 `MIC1~4` 与六脚定义；板上标 `J1(连接器)` 与**第一脚三角标记** |

### G. 器件与工艺

| # | 事项 |
|---|---|
| G1 | **ESD**：MEMS 麦是静电敏感器件（手册有 ESD CAUTION）⇒ 焊接/装配做静电防护 |
| G2 | **首版用座子**（便于换型号/换位置），不直焊 |
| G3 | **引脚总数核对**：`BCLK` 1 + `LRCK` 1 + `SD` 4 + 3.3 V 1 + GND 2 = **9 个脚**（另加 4 个下拉电阻与去耦） |

## 5. 规模与扩展

- 首版 **4 路**（`SD0~SD3`）；
- **板上同时引出 `SD4~SD7`**（脚 21/23/25/27）⇒ 可扩到 **8 路**；
- 上限 8 路（FPGA 侧接收逻辑与数据线数均充裕）。

## 6. 电源

3.3 V 单电源（J1 脚 29），**不需要高精度基准**；中继板保留完整地平面。

## 7. FPGA 侧接口约定（了解即可，不需实现）

- `BCLK` / `LRCK`：由 FPGA 从 50 MHz 分频产生，**全通道共享**；名义 48 kHz 量级，实际速率随分频比（**现有音频链本就用非标准速率，不是新问题**）。
- 接收：**一份 I2S 接收器**（`BCLK`/`LRCK` 计数 + 每通道一个移位寄存器），**按 `LRCK` 取左时隙**，送入频谱链。
- **不需要 CIC 抽取滤波** —— I2S 麦内部已输出 PCM。
- 数据格式（标准 I2S / 左对齐、MSB 位置）**按所选型号手册对齐**。
- 硬件只需保证：**时钟干净、电源干净、走线合理**。

| **BCLK**（共享） | **1** | **D14** | FPGA → 模块 |
| **LRCK**（共享） | **3** | **G12** | FPGA → 模块 |
| **MIC1 `SD`** | **5** | **H13** | 模块 → FPGA（**ANC 误差麦**） |
| **MIC2 `SD`** | **7** | **J14** | 模块 → FPGA |
| **MIC3 `SD`** | **9** | **K12** | 模块 → FPGA |
| **MIC4 `SD`** | **13** | **M14** | 模块 → FPGA |
| **DIN**（功放输出） | **21** | **G16** | **FPGA → 功放（输出！）** |

## 2. ⭐ 新增 A：功放接口（2×4 排针，丝印 `AMP`）

### 2.1 排针定义

| 脚 | 信号 | 说明 |
|---|---|---|
| 1 | BCLK | ← J1-1 |
| 2 | LRCK | ← J1-3 |
| 3 | **DIN** | ← **J1-21（G16）** |
| 4 | GND | ← J1-12/30 |
| 5 | 3.3 V | ← J1-29（供 SD 选择） |
| 6 | **SD 分压点 1.055 V** | 见 §2.3 |
| 7 | GND | 电源回路 |
| 8 | 备用 | 预留第二个功放 |

### 2.2 扩流与滤波（**必做**）

| 元件 | 值 | 位置 | 原因 |
|---|---|---|---|
| **电解电容** | **100 µF / 16 V** | 功放 VIN 与 GND 间，靠近接口 | D 类功放电流脉冲大，压降会带出「嗡嗡」声 |
| **陶瓷电容** | **0.1 µF** | 同上，紧邻 | 高频去耦 |
| **串阻** | **22~33 Ω** | BCLK / LRCK / DIN 各一个，靠 FPGA 侧 | 抑制长线振铃 |

> v1 **没有**串阻，系统工作正常 ⇒ 属增强项；但 **v2 因负载增加（见 §2.2.1），建议改为必做**。
> 位号放 0402 焊盘，**兼容 0 Ω 跳线**（万一反而变差可直接短接）。

### 2.2.1 ⚠️ 四麦 + 功放后的 BCLK / LRCK 扇出

| 项 | v1（3 麦 + 1 功放 = 4） | **v2（4 麦 + 1 功放 = 5）** |
|---|---|---|
| BCLK 频率 | 3.07~3.13 MHz | 同 |
| 负载数 | 4 | **5** |
| 风险 | 可接受 | **扇出增加，必须串阻** |

> 依据：`音频采集板要求.md` **§C2** —— BCLK 余量极小（3.07~3.13 MHz vs 手册上限 3.2 MHz）。

### 2.3 SD 分压与切换

**MAX98357A 的 `SD` 是电压门限选择，不是普通高低电平：**

| SD 电压 | 功能 |
|---|---|
| **< 0.16 V（GND）** | ⛔ **关断，完全无声** |
| 0.16 ~ 0.77 V | (L+R)/2 混合（听不出对比） |
| **0.77 ~ 1.4 V** | ✅ **右槽 = POST（滤波后）** |
| **> 1.4 V（3.3 V）** | ✅ **左槽 = RAW（滤波前）** |

**分压电路（板上固定焊接）**：

```text
3.3 V ── 100 kΩ ──┬── SD 分压点（1.055 V）
                  │
                47 kΩ
                  │
                 GND

标称 1.055 V；最坏偏差（±5%）0.935 ~ 1.185 V，仍在 0.77~1.4 V 内
```

**⚠️ 为什么不用 100k+33k**：标称 0.819 V 看似够，但最坏会掉到 **0.721 V**，跌破 0.77 V 门限 ⇒ 变成「(L+R)/2 混合」⇒ **听不出对比**。

**切换方式：单刀双掷拨动开关（SPDT，ON-ON）**

```text
              ┌── ① 3.3 V ──────→ RAW（滤波前）
   拨动开关 ──┤
              └── ③ 分压 1.055 V ─→ POST（滤波后）
                     │
                   ②（公共端）──→ 功放 SD
```

| 板上设计 | 说明 |
|---|---|
| 预留 **3P** 位 | `3.3V` / `SD` / `分压点`，可插开关或跳线帽 |
| 开关规格 | `SS-12D00` 类，**2 位 3 脚 ON-ON** |
| ⛔ 不要 ON-OFF-ON | 中间档 SD 悬空，音量异常 |
| ⛔ 不要引出 GND 档 | GND = 关断静音，容易误判为"功放坏了" |

> 不装开关时：跳线帽短接「3.3 V — SD」固定 RAW（保底演示够用）。

## 3. ⭐ 新增 A2：误差麦接口（6P 排针，丝印 `ERROR MIC`）

### 3.1 为什么必须走线缆

**ANC 要求误差麦与扬声器距离 3~8 cm**。若焊死在板上而喇叭在别处 ⇒ 距离不可控 ⇒ **ANC 完全失效**。

### 3.2 排针定义

| 脚 | 信号 | 来源 |
|---|---|---|
| 1 | **GND** | J1-12/30 |
| 2 | **VDD** | J1-29（3.3 V） |
| 3 | **SD** | **J1-5（H13）** |
| 4 | **L/R** | GND（固定左槽） |
| 5 | **WS** | J1-3（G12） |
| 6 | **SCK** | J1-1（D14） |

### 3.3 与其余三麦的关系

| 通道 | v2 形式 | 用途 |
|---|---|---|
| **MIC1** | ⭐ **6P 排针 + 线缆** | **ANC 误差麦（可移动）** |
| MIC2/3/4 | 板上模块座 | 三麦均值 |

> **RTL 依据**：`slave_audio_demo_top.v:236` 的 `mic_three_mean_t16` **只取 `pcm1/pcm2/pcm3`**，`pcm0`（MIC1）仅作调试输出 ⇒ **零冲突**。

**丝印必须写**：`ERROR MIC / ANC` + 「使用时放在扬声器前方 3~8 cm」+「不用时不插，不影响三麦均值」。

## 4. ⭐ 麦克风布局与间距（**v2 新增**）

### 4.1 核心矛盾

| 麦克风 | 位置由谁决定 | 要求 |
|---|---|---|
| **MIC1（误差麦）** | **扬声器的位置** | 离喇叭 **3~8 cm** |
| **MIC2/3/4（采集均值）** | **噪声场的位置** | **远离喇叭**（否则频谱被自己输出占满） |

**⇒ 两个要求相反。这正是不建议 MIC1 焊在板上的原因。**

### 4.2 间距要求（三层约束）

| # | 距离 | 要求 | 依据 |
|---|---|---|---|
| **1** | **MIC1 ↔ 扬声器** | **30 ~ 80 mm** | ANC 有效区仅在声源附近；`D-72` 账 6 的 500 Hz 相位预算允许 |
| **2** | **MIC2/3/4 ↔ 扬声器** | **≥ 150 mm** | 喇叭输出会直接进这三路，污染频谱 |
| **3** | **MIC1 ↔ 最近的 MIC2/3/4** | **≥ 100 mm** | 保证三麦在 ANC 安静区之外 |

### 4.3 三麦（MIC2/3/4）内部排布

| 项 | 建议 |
|---|---|
| 两两间距 | **30 ~ 50 mm** |
| 排布 | **三角形**（非直线 —— 直线易同相叠加） |
| 朝向 | 四颗**完全一致** |
| 与噪声源距离 | 大致相等，避免某一路偏响拉偏均值 |

### 4.4 若强行全部上板：板长需要 ≥120 mm

| 板长 | 可实现的 MIC1↔MIC2 距离 | 评价 |
|---|---|---|
| 60 mm | ≈ 45 mm | ❌ 不够 100 mm |
| 80 mm | ≈ 65 mm | ⚠️ 勉强 |
| 100 mm | ≈ 85 mm | 🟡 接近 |
| **120 mm** | ≈ 105 mm | ✅ 达标 |

**布局示意**：

```text
        ┌──────────────────────────────────┐
        │  ●MIC2        ●MIC3              │  三麦区
        │                                  │  （三角形）
        │  ●MIC4                           │
        │                                  │
        │  ═══════════ 分隔带 ═══════════   │  间距 ≥100 mm
        │                                  │
        │                        ●MIC1     │  误差麦区
        └──────────────────────────────────┘
                                  ↕ 30~80 mm
                              [ 扬声器 ]
```

**⇒ 推荐仍是 §3 的「MIC1 走线缆」，板长可回到 60~80 mm。**

## 5. ⭐ 信号完整性（**v2 强化**）

| # | 规则 | 原因 |
|---|---|---|
| **S1** | **BCLK / LRCK 源端串 22~33 Ω**（靠 FPGA 侧） | 频率 3.07~3.13 MHz，上限 3.2 MHz，余量极小 |
| **S2** | **走线尽量短**（<20 mm 至各模块座） | 长支线造成振铃/过冲 |
| **S3** | **`SD` 不得与 `BCLK` 长距离并行** | BCLK 会耦合进高阻的 SD |
| **S4** | **保持完整地平面** | 不在 BCLK/SD 下方开槽，保证回流连续 |
| **S5** | **不需要等长** | 3 MHz 在板级属低频段，差折算到时间是亚纳秒量级，抠等长是白费功夫 |
| **S6** | **每路 `SD` 留 100 kΩ 下拉** | 半周期高阻，防浮空 |
| **S7** | **功放 BCLK/LRC 分支也要串阻** | 与 §2.2.1 的 5 负载配合 |

## 6. ⭐ 电源与去耦

| # | 项 | 规格 |
|---|---|---|
| **P1** | 麦克风供电 | **3.3 V 单电源**（INMP441 宽压 1.62~3.63 V，免 LDO） |
| **P2** | 每模块去耦 | **0.1 µF**，紧贴 `VDD`-`GND` |
| **P3** | 总入口去耦 | **10 µF 电解 + 0.1 µF 陶瓷** |
| **P4** | **功放不从中继板取电** | 功放 VCC 走**独立 5V**（USB 只有 500 mA，功放峰值 **≈0.73 A**） |
| **P5** | **功放 VIN 就近去耦** | **100 µF + 0.1 µF**（§2.2） |
| **P6** | ⛔ **J1-11（VCC5V）绝不接任何线** | 致命（A2） |

**⚠️ 为什么功放不能用 FPGA 的 5V**：
1. 本板**只能 USB 供电**（板卡手册），USB 2.0 = **500 mA @ 5 V = 2.5 W**
2. 功放峰值 **0.73 A** ⇒ 单项就超容量
3. D 类功放电流脉冲会污染 5V 轨 → 经 LDO 传入 FPGA 的 3.3V → **时序劣化 / 音频自激**
