# 误差麦 FPC 改造方案（2026-10-29）

> **目的**：把误差麦（MIC1）的 20 cm 散装杜邦线，换成 **FPC 软板 + 载板**
> **要解决的三个问题**：① 回流路径差 ② 紧贴 D 类功放受干扰 ③ 线束晃动导致接触间歇
> **基底**：`docs/中继板规格_v1冻结与v2设计.md` 的 v2 设计

---

## 0. 一句话

**FPC 的价值不在"软"，在于能做成「一信号一地」的固定几何 + 地平面 —— 这才是杜邦线做不到的。**

| 问题 | FPC 能否解决 |
|---|---|
| 回流路径差 | ✅ 能（地平面 + 交错地） |
| 线缆晃动 / 接触间歇 | ✅ 能（固定几何） |
| 紧贴 D 类功放的辐射 | 🟡 部分（可选屏蔽层） |
| **L/R 未接地** | ❌ 与线材无关，必须在载板处理 |
| **模块本身质量问题** | ❌ 与线材无关 |

## 三、FPC 引脚分配（**8 芯 · 0.5 mm 间距**）

**原则：每个信号一根紧邻的地。**

| Pin | 信号 | 说明 |
|---|---|---|
| **1** | VDD | 3.3 V |
| **2** | GND | VDD 回流 |
| **3** | **SD** | ⭐ 麦克风数据（最关键） |
| **4** | GND | SD 回流 |
| **5** | SCK | 位时钟 3.07~3.13 MHz |
| **6** | GND | SCK 回流 |
| **7** | WS | 帧时钟 48 kHz |
| **8** | GND | WS 回流 |

```text
  截面示意：

  ┌─────────────────────────────────────────────┐
  │ Pin:  1     2     3     4     5     6     7     8 │
  │      VDD   GND    SD   GND   SCK   GND    WS   GND│
  └─────────────────────────────────────────────┘
       每根信号两侧都有地 ⇒ 回流路径最短
```

**⚠️ `L/R` 不占 FPC 引脚** —— 在**载板上直接焊死接地**（它不需要走线）。

> 若 8 芯不便，可用 **10 芯**（两侧各加一根 GND），效果更好。

## 四、中继板改造

### 4.1 把 `ERROR MIC` 6P 排针换成 FPC ZIF 座

| 项 | 规格 |
|---|---|
| 连接器 | **FPC/FFC 0.5 mm 间距、8 芯 ZIF**（下接或上接按装配方向定） |
| 型号参考 | 常规 0.5mm 8P 翻盖式（如 FH12 系列兼容件） |
| 位置 | 原 `ERROR MIC` 排针位置，**靠板边**（便于 FPC 引出） |

### 4.2 ⚠️ MIC1 模块座保留，但加选择跳线

```text
        ┌── MIC1 座（板上直插）
  SD ───┤
        └── FPC 座（引出）
```

**理由**：模块座与 FPC 同时接着 = 两个负载挂同一组线。

**⇒ 加 3P 跳线或 0 Ω 选择；或 MIC1 座只焊不接线（默认走 FPC）。**

### 4.3 串联电阻（**必做**）

| 位置 | 阻值 | 说明 |
|---|---|---|
| **SCK** | **22~33 Ω** | 靠 FPGA 侧（中继板上） |
| **WS** | 22~33 Ω | 同上 |
| **SD** | 22~33 Ω | 靠**载板端**（数据方向相反） |

### 4.4 保留项

- **MIC1 的 100 kΩ 下拉**（与 FPC 并联，不影响）
- FPC 座旁 **0.1 µF**（VDD-GND）

### 4.5 中继板布局（俯视 · 建议）

```text
        ┌──────────────────────────────────────────────┐
        │  板边（靠 J1 一侧）                          │
        │  ┌────────────────────────────────────────┐ │
        │  │              J1 2×20 母座               │ │
        │  └────────────────────────────────────────┘ │
        │                                              │
        │   ┌──────┐  ┌──────┐  ┌──────┐             │
        │   │MIC2座│  │MIC3座│  │MIC4座│             │
        │   └──────┘  └──────┘  └──────┘             │
        │                                              │
        │   ┌──────┐           ┌────────────┐         │
        │   │MIC1座│           │  AMP 2×4   │         │
        │   └──┬───┘           └────────────┘         │
        │      │ [跳线]                                │
        │   ┌──┴────────┐   ┌─────────┐              │
        │   │  FPC 8P座  │   │ 扩展 2×7│              │
        │   └────────────┘   └─────────┘              │
        │                                              │
        │   ● BCK  ● LRCK  ● SD  ● GND  ● DIN         │  ← 测试点
        └──────────────────────────────────────────────┘
                  ↑ FPC 从这一边引出（板边）
```

**要点**：FPC 座放板边、测试点集中、MIC1 座与 FPC 座相邻。

## 五、载板（15 × 20 mm）

### 5.1 规格

| 项 | 建议 |
|---|---|
| 尺寸 | **约 15 × 20 mm** |
| 层数 | **2 层**（顶层信号 + 底层完整地） |
| 连接 | **FPC 直接焊在载板上**（省一个 ZIF 座，更可靠） |

### 5.2 载板必须做的五件事

| # | 项 | 原因 |
|---|---|---|
| **1** | ⭐ **L/R 直接焊死接 GND** | **"时好时坏"的头号原因** |
| **2** | **0.1 µF 紧贴模块 VDD** | 滤掉沿线传入的噪声 |
| **3** | **底层完整地平面** | 回流路径 |
| **4** | **INMP441 6P 模块座** | 与中继板一致，便于换模块 |
| **5** | **进音开孔** | 模块底部进音 |

### 5.3 六脚对应

| 模块引脚 | 载板 |
|---|---|
| GND | GND |
| VDD | VDD（经 0.1 µF 到 GND） |
| SD | SD（串 22~33 Ω） |
| **L/R** | **直接接 GND（焊死）** |
| WS | WS（串 22~33 Ω） |
| SCK | SCK（串 22~33 Ω） |

### 5.4 载板布局（俯视）

```text
        ┌───────────────────────┐
        │   顶层                │
        │  ┌─────────────────┐  │
        │  │  INMP441 6P座    │  │
        │  │   ┌─────────┐   │  │
        │  │   │ ● 进音孔 │   │  │  ← 对准模块底部进音面
        │  │   └─────────┘   │  │
        │  └─────────────────┘  │
        │                       │
        │  [22Ω] [22Ω] [22Ω]    │  ← SCK / WS / SD
        │  [0.1µF]              │  ← 紧贴模块 VDD
        │                       │
        │  ┌─────────────────┐  │
        │  │  FPC 焊盘 8 点   │  │
        │  └─────────────────┘  │
        └───────────────────────┘

        ┌───────────────────────┐
        │   底层                │
        │   整片地平面（不分割） │
        └───────────────────────┘
```

## 六、FPC 打样参数

| 项 | 建议值 |
|---|---|
| 芯数 | **8**（或 10） |
| 间距 | **0.5 mm** |
| 长度 | **100 ~ 150 mm** |
| 补强板 | **两端各 ≥ 8 mm** |
| 铜箔 | 常规 1 oz |
| **屏蔽层** | 🟡 可选（加钱，对外界干扰额外有帮助） |
| 工艺 | **加急** |

**长度为什么取 100~150 mm**：误差麦要离喇叭 3~8 cm，中继板要离喇叭 ≥15 cm ⇒ 正好。

## 七、⚠️ 四条设计红线

| # | 红线 | 后果 |
|---|---|---|
| **1** | **载板 L/R 必须焊死接 GND** | 否则麦克风可能输出右槽 ⇒ 接收器读不到 ⇒ **时好时坏** |
| **2** | **FPC 装反（Pin1 错位）** | VDD/GND 对调 ⇒ **烧模块** |
| **3** | **屏蔽层不能两端接地** | 形成地环路 ⇒ **反而引入噪声** |
| **4** | **FPC 不能急弯**（弯曲半径 ≥3 mm） | 铜箔断裂 |

## 八、与现有 v2 规格的差异

| 项 | v2 原设计 | **FPC 改造后** |
|---|---|---|
| `ERROR MIC` | 6P 排针 | **8P FPC ZIF 座** |
| 误差麦连接 | 杜邦线 | **FPC + 载板** |
| 载板 | 无 | **新增（15×20 mm）** |
| MIC1 座 | 保留 | 保留（加选择跳线或不接线） |
| 其余三个麦 | 板上模块座 | **不变** |
| AMP 接口 | 2×4 排针 | **不变** |
| 扩展 IO | 2×7 排针 | **不变** |
| 测试点 | 已有 | **增加 FPC 座旁各信号测试点** |

## 九、打样前检查清单

**中继板**
- [ ] FPC 8P ZIF 座（0.5 mm），靠板边
- [ ] MIC1 座与 FPC 座之间有选择跳线
- [ ] SCK / WS 各串 **22~33 Ω**
- [ ] MIC1 SD 保留 **100 kΩ 下拉**
- [ ] FPC 座旁 **0.1 µF**
- [ ] 测试点：BCLK / LRCK / SD / GND / DIN

**载板**
- [ ] **L/R 焊死接 GND**
- [ ] **0.1 µF 紧贴 VDD**
- [ ] 底层**完整地平面**
- [ ] SCK / WS / SD 各串 **22~33 Ω**
- [ ] 进音孔对准模块进音面
- [ ] FPC 焊盘 8 点，Pin1 有丝印标记

**FPC**
- [ ] 8 芯 / 0.5 mm / 100~150 mm / 两端补强
- [ ] 屏蔽层**单端接地**
