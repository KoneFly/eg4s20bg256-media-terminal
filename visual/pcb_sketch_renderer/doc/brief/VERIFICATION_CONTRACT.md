## 场景列表

**核心判据（全部场景共有）**：把 `label.bin` + 该场景的 `image.bin` 按行主序逐拍送入 DUT（`in_valid` 恒 1），
收集全部输出像素，与 `expect.bin` **逐位比对全帧 307,200 像素**；任何 1 bit 差异即 FAIL 并打印首个失配的行列与两值。

| # | 场景 | 刺激 | 检查项 |
|---|---|---|---|
| S1 | `boot_done` | 状态表 = 启动完成静音快照；`ov_on=0`；图像全 0 | 全帧逐位 == `expect.bin`；非零像素 53,938 |
| S2 | `play_low` | 播放 1s 快照（低频）；`ov_on=0` | 全帧逐位相等 |
| S3 | `play_mid` | 播放 5s 快照（中频，脉冲在场）；`ov_on=0` | 全帧逐位相等（覆盖脉冲 3 槽与 `age<3` 升沿） |
| S4 | `play_high` | 播放 9s 快照（高频，彗星在场）；`ov_on=0` | 全帧逐位相等（覆盖 class 4 彗星尾 90 项） |
| S5 | `grow_half` | 第 90 帧（生长半程）；`ov_on=0` | 全帧逐位相等（覆盖"未长到"分支与亚像素前沿） |
| S6 | `saturate` | 手工置满（全段 255 / 柱顶 / 节点全亮 / 脉冲头在 60）；`ov_on=0` | 全帧逐位相等（覆盖各饱和与边界裁剪） |
| S7 | `all_zero` | 状态表全零 + `chip_ink=0` | 全帧逐位相等（覆盖"全黑 + 环/柱基线仍在"的边界） |
| S8 | `overlay_thirds` | 叠加模式 + 三区底图（暗/中/亮各 1/3）；`core_q8=90` | 全帧逐位相等（覆盖 `Y≥128` 两支与 3/8 深色线） |
| S9 | `overlay_grad` | 叠加模式 + 渐变棋盘底图 | 全帧逐位相等（覆盖 `m` 四档与柱形图带压暗 1/2） |

**协议/时序检查（每个场景都做）**：

| 检查项 | 判据 |
|---|---|
| 固定延迟 | 从首个 `in_valid` 到首个 `pixel_valid` 的拍数 = 常数；**整帧内该值不变**（无气泡） |
| 吞吐 | `in_valid` 恒 1 时 `pixel_valid` 无间断；有效像素数 == 307,200 |
| 复位 | 中途 `rst_n` 拉低 → 输出清零、行缓存指针归零；复位后重新送流仍逐位正确 |
| 状态表写 | 在 `wr_clk` 域写入后，`clk` 域读回一致（跨域读写一致性；写与读不同时进行） |

## TestBench架构要求

| 项 | 要求 |
|---|---|
| **激励时基** | 本模块输出为**寄存器输出**（`pixel_rgb565`/`pixel_valid` 为 reg）⇒ 检查用 **上升沿 NBA 后观测**（"@posedge 后 #1 采样"，不得用同拍阻塞赋值前的值） |
| 时钟 | 两个时钟：`clk` 与 `wr_clk`（建议 40ns / 20ns，**仅仿真节拍，不代表真实 39.68ns/20ns**，须注释说明）；两者相位关系不敏感（真双口 BRAM） |
| 存储加载 | `$readmemh` 装载 `state_trace.hex` / `state_misc.hex` 到 TB 侧数组，再经 `wr_*` 口写入 DUT（**通过真实写口，不后门强写**）；`label.bin` / `image.bin` / `expect.bin` 用 `$fopen/$fread` 二进制读入 |
| 从机模型 | 无（DUT 无背压端口） |
| 看门狗 | 单场景墙钟 >60s 未跑完 ⇒ `$display("TIMEOUT")` + `$finish`（**超时与失配分开报告**） |
| 计数器 | 输入像素计数、输出像素计数、失配计数（首个失配打印 `x,y,exp,got`）、延迟测量寄存器 |
| **失败即停** | 首个失配打印详情后 `$finish`（fail-fast），避免长日志 |
| 结构 | `tb_top.v` + `dut_inst.vh`（实例化头，端口列表与 `INTERFACE_SPEC.md` 逐字一致）；参数化 `CASE_DIR`（`+define+` 或 `$value$plusargs`）以复用同一 TB 跑 9 个场景 |

## 边界与规模覆盖

| 项 | 回答 |
|---|---|
| **位选掩码自查** | 本模块所有字段提取**均为定宽位选**（如 `label[12:8]`），无 `case (idx[3:0])` 型同余别名风险；但 class 解码 `case (label[15:13])` 必须是**全 3 位**，不得写成 `case (label[15:13])` 之外的截断形式 |
| **真实尺寸/超长场景** | 全帧 307,200 像素 × 9 场景 = **2,764,800 像素逐位比对**，全部为真实尺寸（无小样本）；`label.bin` 是**完整的 640×480 真实标签图**，含全部 8 类；`saturate` 场景覆盖各字段上界，`all_zero` 覆盖下界 |
| **字段污染枚举** | 标签字段命中位置：`[15:13]` 全局 class 解码；`[12:8]` 墨量（class 1/7）；`[7]` 核心位（class 1）；`[6:4]` 刻度（class 1）；`[12:7]` 线号低 6 位（class 2/3）；`[6:0]` 路径下标（class 2/3）；`[12:3]` 角度（class 4）；`[12:6]` 柱号/节点号（class 5/6）；`[5:0]` 径向偏移（class 5）；`[5:4]` 部位（class 6）；`[3:0]` 墨量档（class 6）；`[7:0]` 墨量（class 7）。九场景合起来覆盖全部字段的所有取值区间 |

## 分层与时间预算

> 依据项目策略：**默认不跑仿真，优先出 bit 上板**；下列档位按需使用。

| 档位 | 内容 | 预计耗时 |
|---|---|---|
| **L0 冒烟** | 编译 + `boot_done` 单场景（全帧比对） | **< 2 分钟** |
| **L1 快速** | 9 场景全跑（每场景 307,200 像素流） | **10~25 分钟**（估算：每像素 1 拍 × 307,200 × 40ns ≈ 12.3ms 仿真时间/场景；Verilator 下更快） |
| **L2 全量** | L1 + 复位中途重入 + 写读一致性 + 变异证伪（**仅交付前一次**） | **≤1 小时** |

`sim/run.sh` 必须提供 `PROFILE=quick|full` 档位与 `SCEN_ONLY=<name>` 单场景运行。

## 提速措施

| 手段 | 采用 | 说明 |
|---|---|---|
| **WSL/Verilator 评估** | **建议采用** | 本模块**不含任何厂商 IP**（仅 BRAM/ROM 行为模型），TB 无加密 IP ⇒ **Verilator 迁移代价低**。9 场景 × 307,200 拍，iverilog 可能 >5 分钟/场景 ⇒ **建议直接用 Verilator**（预计 100× 量级提速），TB 需 C++ 改写或用 Verilator 的 `--binary` + 简易 C 驱动 |
| fail-fast | ✅ 必须 | 首个失配即 `$finish`，日志限流 |
| 仿真专用缩放 | ❌ 不适用 | 时序无关（纯同步 + 固定延迟），无需缩放；**时钟周期仅影响墙钟，不影响判据** |
| 抽样对拍 | ❌ 禁止 | 本任务**逐位全帧**是核心判据，不得抽样 |
| 变异测试降级 | ✅ 交付前一次 | 至少 1 个变异（如把 `>>8` 改成 `>>7`）证明 TB 能杀 |
| 长仿真分片 | ✅ | `SCEN_ONLY` 支持单场景跑，九个场景可分发 |

> **红线**：全帧逐位不得削减；**上板前置 = 编译 0 错 0 警 + bit 已登记 `BURN_INDEX.md`**（仿真不构成上板前置）。

## 验收门槛

1. 编译 **0 错误 0 警告**（`sim/compile.log` 为空文件）；
2. **9 场景全 PASS**（每场景全帧 307,200 像素逐位相等，失配数 0）；
3. 协议/时序检查 4 项全 PASS（固定延迟、吞吐、复位、跨域写读）；
4. `sim/sim_result.json` 结构化输出（三态计数：PASS/FAIL/TIMEOUT）；
5. 变异测试：≥1 个变异被 TB 杀死（附 `run_report.md` 证据）；
6. `doc/output/behavior_spec.md` 声明固定延迟数值与实际一致。
