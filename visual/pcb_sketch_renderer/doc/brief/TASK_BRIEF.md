# Task Brief — pcb_pixel_renderer（M6 PCB 线稿频谱 · 像素渲染器）

> 签发：浮浮酱（视觉线架构）｜ 日期：2026-09-27 ｜ 状态：**待主人转交执行方**
> 上游：`spec/M6_PCB_SKETCH.md`（效果规格）· `golden/pcb/`（标签图与对象表 ROM）· `spec/M6_PCB_PORTING_PLAN.md`（移植总方案）
> 本任务属于移植计划 **S2**（S1 已完成：标签图与 ROM 已产出并自检通过）

---

## Task Summary

把「16bit 标签 + 16bit 图像像素」的逐拍像素流，按冻结的状态表合成为最终 RGB565 输出——
即 M6 可视化层（芯片/走线/音柱/粒子/底部柱形图）的**全部逐像素着色**。

---

## Scope

**做**：
1. 标签解码（8 个 class）→ 按 class 查冻结的状态表 → 得到该像素的「墨线亮度 dark」与「发光亮度 light」；
2. 底部常驻 128 路柱形图（procedural，由 x 反推通道；独立平面，不受叠加开关影响）；
3. 3px 线宽：光/墨两层各做一次 3×3 最大值膨胀（可分离：行 → 列，各需 2 行缓存）；
4. 径向/通道调色板索引（逐行增量法，无开方无除法）+ 32 档亮度量化 + 高光混白 → RGB565（黑底模式）；
5. 叠加模式（拨码 ON）：与输入图像像素做亮度自适应混合（§叠加合成）。

**不做**（本任务边界）：
- ❌ 不产生视频时序（hsync/vsync/de）、不封装 AXIS —— 主线负责；
- ❌ 不做每帧状态更新（生长/起音/脉冲/包络）—— 那是 S3 `pcb_frame_updater` 的职责，
  本模块**只读**状态表；
- ❌ 不做频谱分析（S4）；
- ❌ 不做 SDRAM 取数、标签行缓存、请求仲裁（S6b 主线集成包）；
- ❌ 不做纸底模式（纸底仅浏览器原型用途，上板不需要）；
- ❌ 不做标签图加载（S6a）；
- ❌ **不做音柱粒子与柱顶连线**（动态覆盖层）—— 归 **S2b**（按行分桶的覆盖层光栅化）：
  该层每帧约 1150 条短线段，需要 S3 在消隐期按行分桶后再逐行光栅化，与本模块的逐像素查表路径不同，
  混在一起会让本模块无法独立验收。**本任务的黄金向量已把这两项置零。**

## 硬件约束（Hardware Constraints）

| 项 | 值/说明 |
|---|---|
| 器件 | 安路 EG4S20BG256（HX4S20C 板） |
| 时钟域 | **像素域 25.2MHz**（`clk`）；状态表写口在 **ctrl 域 50MHz**（`wr_clk`，集成时由 S3 驱动） |
| 状态表 | **真双口 BRAM**（写 ctrl 域 / 读像素域）。两张：`st_trace` 逻辑宽 128bit×128 深、`st_misc` 32bit×256 深 |
| 行缓存 | 3×3 膨胀需 2 行 × 640 × 16bit（光/墨各 8bit）≈ 2 块 BRAM9K |
| 半径索引 | **无 ROM**：逐行增量法（`s = dx²+dy²` 递增 + 双向比较调整 `r`），详见 `INTERFACE_SPEC.md §③` |
| 调色板 | 64 项基色 ROM；展开为 (idx × 亮度档) 表可省 DSP（见 `INTERFACE_SPEC.md §④`） |
| 调色板 ROM | 64×24bit（径向基色）+ 白混表（见 §输出级） |
| 片上 vs 外部 | **全部片上**；无外部存储访问、无引脚约束 |
| 输出位宽 | RGB565 = `{R[4:0], G[5:0], B[4:0]}`，与主线 `rgb888_to_rgb565` 反向对应 |

## IP复用评估

| 候选 IP | 明文/加密 | 可替代的自研工作量 | 决策 |
|---|---|---|---|
| TD `RAM`（真双口 BRAM） | 明文 | 自研 BRAM 不可行（须用原语） | **选用**（状态表、行缓存） |
| TD `ROM` | 明文 | 分布式 ROM 可由 `case`/LUTRAM 推断 | **选用**（调色板/半径表） |
| TD `Divider` | 明文 | 本模块**不需要除法**（径向用逐行增量比较，见 §输出级） | 否决（不需要） |
| TD `CORDIC` | 明文 | 半径计算已改为逐行增量法，无需开方 | 否决（不需要） |
| TD `FFT`/`FIR`/`CIC` | 明文 | 频谱前端（S4）用，与本模块无关 | 不适用 |
| TD `Video NPU`/`Scaler` | 加密 | 本模块是逐像素查表着色，非缩放 | 否决（不适用，且加密 IP 无法 iverilog 仿真） |

> 结论：本模块**不引入任何需要仿真的厂商 IP**，只用 BRAM/ROM 原语 ⇒ 可全程用 Verilator/iverilog 验证。

## 调试与可观测性设计

| 失败分支 | 可观察现象 | 建议探针 |
|---|---|---|
| 状态表未初始化 | 全屏只有静态墨线，无发光 | `dbg_st_init_done`（1bit，写口收到过 ≥1 次写） |
| 标签流断流（in_valid 恒 0） | 输出恒 0 | `dbg_in_cnt[15:0]`（入像素计数） |
| class 解码异常 | 某类像素全黑/全亮 | `dbg_cls[2:0]`（当前像素 class，3bit） |
| 膨胀行缓存指针错位 | 竖向条纹 | `dbg_lb_wr_y[8:0]`、`dbg_lb_rd_y[8:0]` |
| 叠加模式亮度判据错 | 亮底上线条消失 | `dbg_y_hi`（1bit，Y≥128 标志） |

**失败码规则**：`dbg_err[3:0]` sticky 锁存首个异常（`1`=状态表从未写入、`2`=in_valid 连续 4096 拍为低但在 DE 内、`3`=标签 class 越界），
**超时与数据失配分开编码**（本模块不产生数据失配，失配由 TB 判定）。

**ChipWatcher 探针建议**（取最小必要）：`dbg_cls[2:0]` + `dbg_err[3:0]` + `dbg_in_cnt[15:0]` 三条即可覆盖主要分支；
**建议用 `Read Design 后界面标记`，不在源码留 `MARK_DEBUG`**（若必须留痕，交付前清理）。

## 验收结果（目标）

1. 编译 **0 错误 0 警告**；
2. **逐像素黄金**：**9 组**状态快照 × 全帧 640×480 = 2,764,800 像素，`pixel_rgb565` 与黄金**逐位相等**
   （非叠加 7 组 + 叠加 2 组；用例见 `VERIFICATION_CONTRACT.md §1`）；
3. 1 像素/拍的吞吐：连续 DE 期间每拍输出一个像素，无气泡；
4. 固定延迟：从入像素到出像素的延迟为**常数**（写进 `behavior_spec.md` 并在 TB 断言）；
5. TD 独立综合：资源 ≤ 任务预算（见 §六维），且**输出已寄存**（不向显示链直插组合逻辑）；
6. 边界场景（§VERIFICATION_CONTRACT）全 PASS。

## 重要提醒

1. **状态表布局是冻结契约**（`INTERFACE_SPEC.md` §状态表内存图），S3 依此写入；实现不得变更字段位置；
2. **黄金来自 JS 参考实现**（`prototype/pcb_model.js`），不是 RTL 公式的复写（LESSON-001）；
3. 逐像素黄金场景是**全帧 307,200 像素**比对，不是抽样；
4. 本模块**不产生时序**，TB 必须自己造 DE 与像素节拍（§VERIFICATION_CONTRACT §TB 架构）；
5. `ov_on` 在 VBLANK 生效（集成方保证），本模块内部不再做跨域同步。

## 六维设计审查

| 维度 | 回答 |
|---|---|
| **功能边界** | 只做「标签/图像 → RGB565」的逐像素着色与合成；不做状态更新、不做取数、不做时序。上游断流时输出 0（不产生错误像素） |
| **时钟域** | 双时钟：读侧像素域 25.2MHz、写侧 ctrl 域 50MHz，状态表用真双口 BRAM 跨越。**唯一跨域点是状态表与 `ov_on`**（`ov_on` 由集成方在 VBLANK 同步后给出，本模块视作静态电平） |
| **资源占用** | 估算：状态表 2 块 BRAM9K、膨胀行缓存 2 块、调色表 1~2 块 ⇒ **≤5 块 ERAM**；LUT 估算 ~1200；**DSP ≤5**（高光混白 3 + `ov_k` 增益 1~2；基色查表用 ROM 展开可免）；对比视觉预算 4000 LUT / 12 ERAM —— 本任务占其中一部分，S6b 与取数/仲裁合并核算 |
| **时序收敛** | 像素域 25.2MHz 无压力；写侧 ctrl 域 50MHz 仅写 BRAM 端口。**输出级必须寄存**（BACKLOG C-2），不在显示链上直插组合逻辑 |
| **稳定性** | 状态表写入仅在 VBLANK、写侧计数器简单；行缓存指针由 y 计数驱动，复位清零；`dbg_err` sticky 锁存异常；in_valid 断流时输出 0 而非残留 |
| **可扩展性** | 对象数量受标签位宽限制（走线 ≤128、节点 ≤128、元件 ≤32、柱 128）；改版图只需重跑 S1 烘焙换 `PCB.BMP` 与 ROM，**不动 RTL**；参数（调色板、白混阈值、膨胀半径）为寄存器或 ROM 常量，改观感不需改结构 |
