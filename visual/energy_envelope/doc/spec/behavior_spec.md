# 八路包络行为规格

每路独立8位无符号状态，复位为0。有效frame_tick时对每路旧E与采样目标T求差；T>E选attack_shift，T<E选release_shift，相等保持。

用9位无符号中间量d=|T−E|，bias=(1<<s)−1，step=(d+bias)>>s。上升E+step、下降E−step。偏置和差值相加最大262，禁止截成8位；最终结果范围0..255，不需饱和补丁。s=0直接追随；s>0时非零差值步长至少1、最多为差值，因而无过冲且可收敛。

hold有效保持旧状态，优先于bypass；bypass有效且不hold时采入目标，仍须tick。复位最高优先级，释放同步完成之前不更新。

八路并行，一次采样沿更新所有lane，无顺序扫描、无部分向量可见状态。新输出寄存器在tick采样沿后有效，下游同沿只能读取旧值。

固定手算向量见reference/envelope_vectors.json（从本文件需../../reference/解析）。验证契约定义完整极值/交互/逐帧集成时序要求。估算新增≤500 LUT、66寄存器、0DSP/0ERAM；不是TD测量值。每条路径按25.2MHz收敛，不利用低tick频率设置宽泛时序例外。
