# M3 色光渲染行为规格

## 坐标与高度

有效画幅x=0..639、y=0..479。槽i起点S=64+64i，局部offset=x−S；height=energy_snapshot[i]>>active_shift，top=420−height。height=0时该槽没有核心或光晕。地平线不依赖能量：y=420且x=48..591。

## 壳层分类

按下列顺序命中，区间均闭合；先命中即停止：

1. 亮顶：offset 12..51，y=top..min(top+1,419)。
2. 核心候选：offset 12..51，y=top+2..419；先执行下节栅格、渐变与亮点分类。
3. 近光顶部（glow≥1）：offset 9..54，y=top−3..top−1。
4. 近光侧面（glow≥2）：offset 9..11或52..54，y=top+2..419。
5. 远光顶部（glow=3）：offset 6..57，y=top−7..top−4。
6. 远光侧面（glow=3）：offset 6..8或55..57，y=top+4..419。
7. 地平线；其余为主题背景。

最大高度255使top=165，不发生负坐标。比较使用至少10位无符号量。核心到槽边至少6像素，邻槽远光仍有12像素间隔，不重叠。

## 核心栅格、渐变与纹理亮点

`cell_x=(offset-12)&7`，`cell_y=(y-top)&7`。任一值≥6时输出背景，形成6×6发光块与2像素间隔。亮顶两行不打孔。

对其余核心像素令`rise=420-y`、`q=height>>2`、`half=height>>1`：`rise>half+q`输出亮顶色，`rise>half`输出核心色，`rise>q`输出近光色，否则输出远光色。这是四级垂直量化渐变，不做除法。

5位`hash=x[4:0]^y[4:0]^frame_phase[4:0]^{band,2'b0}`；若`hash < height[7:5]`，当前有效单元提升为亮顶色。frame_phase在每次frame_commit递增一次、复位511，因此首次有效帧为phase0；帧内保持。亮点无位置/速度寄存器，不属于M5状态粒子。

## RGB565色表

主题0暮色余烬：2EB9,46F8,6EF8,9EF7,DE93,F5AE,F44B,EAE8；背景0022，地平线08A5。

主题1极光潮汐：32FF,3BDF,44BF,5DBE,76BA,8F15,C711,F68F；背景0028，地平线10AA。

主题2月白信号：7412,84B4,9D57,ADD9,C67A,D6FB,E719,F6B6；背景0841，地平线2126。非法主题回退0。

亮顶=`core | 16'h39E7`。近光对R[4:0]/G[5:0]/B[4:0]分别无符号右移1位后重组；远光分别右移2位。禁止整体16位右移。

## 状态与输出

复位、坐标、frame_seen、frame_phase、能量快照、pending/active控制按INTERFACE_SPEC。输出优先级：亮顶/有效核心纹理、近光、远光、地平线、背景。正常有效区即使背景非黑也必须pixel_valid=1；消隐及未锁帧阶段pixel=0。实现不得通过帧缓存、乘法、除法、透明混合或厂商图像IP替代。

## 资源与时序

目标≤1200 LUT/160 REG/0 DSP/0 ERAM。关键组合路径为坐标→栅格/hash/高度分级→色表→分通道移位/OR→像素选择，目标39.683ns周期内收敛。若0拍不收敛，先反馈并由规格方与015/016同步评估固定流水线；不得私加延迟或false_path。
