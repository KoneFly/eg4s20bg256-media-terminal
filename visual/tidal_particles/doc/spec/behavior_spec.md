# M5 潮汐星流行为规格

## 状态

16粒子槽，slot band=`slot[2:0]`。每槽`x[9:0],y[8:0],vx signed[3:0],vy signed[3:0],age[3:0],active`；共享`seed[15:0]`、`cursor[3:0]`、`phase[5:0]`与8×8bit能量快照。初值seed=16'hACE1，其余0，粒子inactive。

LFSR：`next={seed[14:0],seed[15]^seed[13]^seed[12]^seed[10]}`。一次提交用当前seed发射cursor槽，再用next(seed)发射cursor+1槽，最终seed=next(next(seed))，即使能量低于阈值也推进。cursor=(cursor+2)&15，phase=(phase+1)&63。

对旧活动粒子：先计算`sx=x+vx`、`sy=y+vy`，截到x0..639/y0..479；age+1，若新age≥12或新y=0则active=0。然后对两个选择槽，输入能量`E[slot&7]≥32`时覆盖为`x=32+64*band+seed[5:0]`、`y=400-seed[11:6]`、`vx=seed[14:12]-3`、`vy=-1-(E>>5)`、age0、active1；低于阈值时保留更新后的旧槽状态。所有算式要按有符号位宽扩展，不得因4bit环绕把负速度变正。

## 像素函数

输出优先级：活动粒子（slot15先判到slot0）→能量外环→内环→稀疏静态星点→主题背景。

粒子中心P=(px,py)：`|x-px|≤1 && |y-py|≤1`为3×3核；age<4为`palette[band]|16'h39E7`，age4..7为核心色，age8..11为核心分通道右移1。其他点若曼哈顿距离≤4用核心分通道右移2；若`|x-px|≤1`且`py+4≤y≤py+8`也用右移2形成短尾。重叠由高slot覆盖低slot。

环中心(320,270)，dx/abs等均至少11bit有符号。`D=max(|dx|,|dy|)+(min(|dx|,|dy|)>>1)`。方向判定优先：`(|dy|>>1)≥|dx|`→上0/下4；否则`(|dx|>>1)≥|dy|`→右2/左6；否则右上1/右下3/左下5/左上7。`R=95+(E[band]>>2)`。E<16不画外环；其余`|D-R|≤2`亮色、≤6核心色、≤11核心分通道右移2。固定内环`|D-83|≤1`用band7分通道右移2。

星点条件：x/y低5位均0、`((x>>5)^(y>>5))&3==0`，用band7弱色。主题背景RGB565为0022/0028/0841。三套核心色表同M3；分通道移位禁止整体16bit移位。

## 时序与资源

有效像素每拍一个，0拍组合输出。状态只在场提交更新；当前场内坐标驱动环与粒子比较。预算≤1100 LUT/≤650 REG/0DSP/0ERAM；这仅是估算。关键路径：16槽并行位置比较→优先级选择，或坐标绝对值→D→方向→R→颜色。需要TD时序报告证明25.2MHz收敛；不允许私加像素延迟。
