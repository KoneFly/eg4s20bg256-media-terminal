# M4 连续频谱脊线启动说明

候选包中间检验通过、正式立项并由用户启动实现方后执行。

1. `../../LESSONS_LEARNED.md`

## 上游依赖

Task020为坐标/ADC/HDMI权威；Task014/017为第一阶段能量链；Task024为第二阶段真能量（TSMIN≥35拍、tick后≤34拍更新）；Task015/016为下游。以正式源码为准，不修改上游。

## 分阶段计划

核对插值黄金→RTL→编译→SR01–17独立TB→五变异→模块TD→交接报告。handoff_packet必须含最小探针、A/B预期映射、Task020 ADC表及“先017后024”的两阶段集成门禁。

## 代码合规摘要（**2026-09-18 起必附**，验收方补）

- **全部层级均可直接搬用**（底层/中层/上层），只要源码**不完全一样**（改模块名/信号名 + 接口适配），
  **不再要求逐行重写**；
- **告知从简**（整模块 / 上层功能 / 官方例程来源 → 告知主人）；**登记从全**
  （**每一次搬用一律登记** `../../../docs/PROJECT_LEDGER.md`，**当轮登记**）；
- **仍然禁止**：① 逐字节相同的文件；② 对外交付源码/注释中的来源指向性表述；
  ③ **明文 IP 源码**复制进 `rtl/`；④ 隐瞒来源；
- ⚠️ **本任务已识别的素材陷阱**：**不得使用含 Xilinx 专有限制的 `tile_ram.v`**；
  `10_fft_1024` 受 **CC BY-NC-SA 2.0（非商用）**限制（详见 `visual_workspace/ASSET_INVENTORY.md` §8.3）。
