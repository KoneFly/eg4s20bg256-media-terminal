# A4 只读计数位历史与复位事件实验

依据用户A3真卡实测：d0=05463/d7=65280校准正确，d6=20480确认BOOT/SD INIT IDLE/reader IDLE/eng_init1；d1/d4变化，d2=57344固定即watchdog高13位0，仍无线稿。原始证据与静态29位/启动比较核对见 `doc/output/A3_PROBE_BOARD_READBACK_CONFIRMED_20261006.json`、`A3_PROBE_BOOT_COUNTER_STATIC_20261006.json`。

本轮只改变隔离副本的 `rtl/v9_udp_m6_master_top.v` 临时观测模块和只读连接，保留A3原功能RTL、两级MISO、功能watchdog及状态机、PLL、SPI/SDRAM/CRC、卡内容、W2/S2效果、所有上游及已封存位。变换可精确还原A3；同时沿用R2/五驱动/94项源与受保护81项核验。软件11加载用例、2快照用例、严格lint及应用告警OPEN不变，增加只读事件测试。

SW0=1：d0=05464；d1=watchdog低16位“曾为1”的按位OR历史；d2低13位为watchdog高13位历史、bit13 CTRL复位释放、bit14 PLL锁定、bit15 KEY1；d3/d5/d6保留A3；d7固定65280。历史不是最大值，不能作为同一时刻计数。d4为锁存事件标志：[0]watchdog bit16曾为1，[1]watchdog恰等499999曾被采样，[2]加载状态曾非BOOT，[3]BOOT观测期间bit15曾1→0，[4]首次释放后CTRL复位曾重现，[5]首次释放后PLL曾解锁，[6]CTRL边沿曾出现，[7]状态曾>11。KEY1清除两个观察域；内部复位不能清除已锁存的证据。

复位监视由原基准50MHz时钟驱动，两级采样，首次CTRL复位释放且PLL锁定后才武装；启动正常复位不记为异常。CTRL复位释放监视保留原关联时钟定时，不增加宽泛豁免；硬宏PLL锁定状态经两级采样，不能把STA通过解释成异步事件捕获率保证。短脉冲漏采、观察自身布局扰动仍是限制，模型不替代真卡。

CTRL实际频率尚未测定，边沿活动不能单独排除频率异常或证明进位故障。位历史与复位标志用于下一步交叉判断，不承诺无标志就排除所有复位或时钟异常。

门禁沿用：MSlice<4900留正余量（目标≤4850）；最终Setup/Hold 0/0、精确CDC/ROM及只读探针物理审计。仍由用户烧主板，副板7175ECC3、受控TF卡不改。页切换等待≥0.3秒；先校准再KEY1复现，放开12秒抄d1～d6并10秒后复读。若线稿出现仍需≥10分钟稳定，不能凭单次成功唯一归因。
