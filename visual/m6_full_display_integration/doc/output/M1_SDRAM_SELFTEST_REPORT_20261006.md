## 自检内容及验证

8个BL8块字地址：040000、0400F8、040100、0401F8、080000、0800F8、100000、1800F8，共64字，覆盖全部4个bank及行/列边界附近。每字分别写入地址编码与反码，区分邻字/拍错位。每组执行64次单字写、8次即时BL8读、保持200000 CTRL拍（4ms）并验证出现刷新确认、再8次BL8读。

两组完成后冻结“通过”快照，此时累计128写、256正确读字；保持刷新，持续每4ms巡检64字。后续首错替换成功快照，此后冻结；16位运行计数饱和，避免绕回误读。请求/响应或初始化等待超65535 CTRL拍生成明确错误，视频始终独立输出彩条。

## 上板操作与固定读数

主板烧BDDEBAE7，保持原接线和HDMI-B。KEY1是RTL名称、对应本板**丝印KEY2**；按约1秒，放开等2秒。彩条应持续正常；SW0只切换诊断显示，任何状态都不门控视频。

**SW0=1**，SW[3:1]选000～111，每页至少等待0.3秒后读数：

| 页 | 前缀 | 通过预期 | 含义 |
|---|---|---:|---|
| 000 | d0 | **05466** | M1版本 |
| 001 | d1 | **00127** | 初始化、写入、即时读、保持读、反码、刷新、首次通过，共7位全部置1 |
| 010 | d2 | **00000** | 错误与失败阶段；0表示没有发布错误 |
| 011 | d3 | **00255** | 冻结地址低16位 |
| 100 | d4 | **00024** | 地址高5位；完整最后字地址1800FF |
| 101 | d5 | **23130** | 预期数据低16位（5A5A） |
| 110 | d6 | **23130** | 实际数据低16位 |
| 111 | d7 | **65280** | 固定显示校准 |

**SW0=0**，P页：P0=05466；P1=256（冻结正确读字数）；P2=128（冻结完成写数）；P3为首通过时刷新次数（模型513，判据为有刷新，不硬签真板精确次数）；P4应16639（S1计数、时钟/复位监测健康）；P5/P6均50597（预期/实际数据高16位C5A5）；P7=65280。M1还没有发布快照时，P1/P2/P3临时显示S1的CTRL/MEM/PIXEL相对频率读数。

首次通过之后继续巡检，正常d/P快照保持不变。**先记录上述固定值，再保持≥10分钟复读、KEY1复位后复现**。通过后进入原TF读链自检。

若失败，保持运行不再复位，记录全部d/P页及彩条现象。d1 bit7置1为失败（首次通过后失败时常见255）；d2低8位为错误码，高8位=`{请求方state[2:0],引擎state[4:0]}`，不是十进制拼接。错误码：1初始化超时，2请求接收超时，3响应超时，4BL8拍数异常，5拍地址异常，6数据不匹配，7响应类型错误，8保持期间未观测刷新计数进展，9非法自检态。失败时d3/d4为地址、d5/P5为完整预期32位、d6/P6为实际32位，P1/P2/P3冻结进度。

仅彩条正常、只有d2=0或尚无结果（d1=0）不能判SDRAM通过。此位通过也不等同完整PCB线稿、动态或黄金双CRC通过。
