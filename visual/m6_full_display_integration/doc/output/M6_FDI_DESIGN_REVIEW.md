# M6-FDI 一页方案评审

日期：2026-10-04｜评审已确认并实施；**后续固定RTL物理探测MSlice5099>4900，当前HOLD**，见[实测报告](M6_FDI_INTEGRATION_REPORT.md)。以下为原确认方案，90%实测门禁不变。基座052第四步 `75959E68B425DE7A`，副板 `7175ECC3` 不变；范围为完整标签链、W2、T1/T2、S2及底部128柱。

**载入路径与选择。** 采用 TF→FAT32 根目录 `PCB.BMP`→固定640×480 BMP24纯截断→片上SDRAM。任务副本仅保留一个文件检索、卡协议/FAT簇链、BMP严格格式检查及固定地址递增；保留已验SDRAM命令/刷新/DQ预捕获，裁去图片多槽管理、重采样、转场、音频及全功能帧缓冲管理。这是启动包允许的窄路径适配；不改黄金、052通信应用层或043主线。资产勘误：文件实际 **24bit、921654B（头54B）**，614400B为转换后的16bit标签数据，文件CRC32 `47E2A01D`，正向标签小端CRC32 `9E9CE1C5`。启动写入及全量读回校验通过后才使能标签；失败锁存LED故障并以数码管明确区分卡/文件、格式、校验、读供给错误。

**全资源预算（器件为EG4S20BG256，采用TD `#lut`口径）。** 下表是设计分配，**不是合体实测或门禁PASS**；“替换底数”按移除当前简化S2并加入完整S2+W2推算，保留扫描/通信及其余既有件，新增额度包含T1/T2、加载、行缓存、FIFO、CDC、CRC和诊断。

**引脚与时钟。** SDRAM用片上 `EG_PHY_SDRAM_2M_32`，无新增外部SDRAM脚。TF四脚 `A14/B14/A13/A12` 全部LVCMOS33，与基座46项显式约束及HDMI自动负端交集0；保留已验HDMI映射，预计54/188 pad。官方lab_ex_6证明TF+SDRAM+HDMI共存，lab_ex_4另证TF+SDRAM+Ethernet，不能把lab6称为含网口或照抄其旧HDMI脚。为避免第四PLL，拟仅将现网络PLL**未使用的C1/C3**设为50MHz 0°/180°（DIV20、CPHASE19/9），保留VCO/反馈、C0/C2/C4和HDMI PLL/PHY参数；任务副本显式导出新时钟，生成约束、DQ双相时序及原网口回归均重新核验，当前未测。

**行读取、扫描与W2衔接。** 标签保留槽0尾部32bit字址 `0x40000+(479-y)×320+(x>>1)`；逐行ROM按 `[31:22]x0/[21:12]x1/[9:0]n` 解码，n为连续区段宽，区段内零标签保留，区段外及y≥451补零。480行核对0失配，最大513半字；单项行缓存容量≥640半字，按BL8边界取数（前451行共93456字、最宽264字/行，**不是耗时实测**）。刷新硬优先；启动期写入/校验，运行期标签行填充优先于诊断，不边显边写；按行消费握手防覆盖。`async_pixel_fifo`为1024×32、AFULL_MARGIN36，`{label,image=0}`同拍写入，严格按已验寄存读语义消费；沿用S2648有效拍延迟/帧尾flush与基座双行重定时，不改变HDMI扫描/AXIS。快照仍用原三银行/epoch/500ms离线机制；消隐收齐128字节并握手到50MHz W2，保持T1 512写→T2 140写→DRAIN→commit/done，写口同时驱动真双口表和S2 barcache，消费侧确认commit后回ack。整批写须在消隐窗口完成，首批状态及标签就绪才开放S2；静音按冻结黄金衰减至零，不新增epoch复位语义。
