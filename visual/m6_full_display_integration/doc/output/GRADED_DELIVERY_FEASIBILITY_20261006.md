## 2. 浮浮酱已查明的三个阻塞（评估须逐一正面回答）

### Q1 ★ 频谱数据从哪来？（**最根本**）

**事实**：频谱由副板 FFT（`7175ECC3`）计算。副板经**以太网 UDP** 回传（`292B/type2`）。而 **043 主线完全没有以太网栈**（无 TEMAC / 无 UDP 栈）。

**要求**：列出**所有**可行通道，逐个给出**面积代价 + 风险 + 依赖**：

| 候选通道 | 面积代价 | 风险/依赖 |
|---|---|---|
| (a) **038 GPIO 板间链路**（1.5625 Mbps，余量 186×，**本来就在 043 集成队列里**） | ？ | 带宽需求仅 128×8bit×60Hz ≈ **61 kbps**，理论富余；但**副板输出接口要改**（现为 UDP） |
| (b) 把 052 网络栈并入 043 | ？ | 体量大（`u_udp` 3138 LE + ARP 488 LE + TEMAC…） |
| (c) 板载精简能量检测（不用副板 FFT） | ？ | **024 八段能量实测 4 DSP / 2275 LUT ≈ 594 MSlice**，已超 043 全部余量 |
| (d) 其它（由你提出） | ？ | — |

**必须给出**：哪条通道在 **241 MSlice** 预算内可行；若都不可行，明确写"都不可行"。

### Q2 柱形渲染的最小代价

**事实**：052 第四步的 128 柱是 **045 S2 整体渲染器**（2248 LE）画的，**没有精简版**（`STEP4`：「vendor/m6_s2 逐文件原样复用 task_045 S2」）。

**要求**：
1. 若**只要柱形图、不要 PCB 线稿场景**，最小独立实现多大？（给出设计估算 + 依据）
2. 能否**独立于 S2**？若要重写，明确这是新模块而非"复用"。
3. 043 已有的叠加底座（字幕/OSD 那套）能否承载柱形绘制？复用点在哪？

### Q3 装得下吗？

**事实**：043 `467A` 空闲 **MS 241 / LS 243**（slice 9316/9800）。

**要求**：把 Q1 选定通道 + Q2 渲染代价 + 必要的连线/仲裁，**汇总成一张面积账**，明确回答：

> **能否装入 241 MSlice？**
> - 能 ⇒ 给出总账与余量；
> - 不能 ⇒ 给出**还差多少**，以及**要从哪腾**（并说明与已排队的 041 双线性 / 038 板间链路 / 转场 P2b-P4 的**排产冲突**）。

## 3. 附加要求

1. **不得把"降级"算成回收**：例如假设"S2 只画柱形图所以省 X LE"必须在有依据的前提下给，且标注等级。
2. **依据等级照旧三档分明**：已有门级实测 / 模块级探针 / 纯设计估算，**不得混计**。
3. **不得动 043 生产树**（`467A`）与任何冻结件；评估用隔离原型或纯设计估算。
4. **M6 侧的 0x46 修复线并行推进**（位 2 要留作独立演示位），两条线互不阻塞。
5. **若评估结论是"不可行"或"需先腾空间"，照实写** —— 这比凑一个能过的数字有用得多。
