## 板上一次记录

只换主板烧上述S1，连接HDMI-B。置SW0=1，确认d0=**05465**、d7=**65280**；KEY1按住约1秒放开，等2秒逐页读取，每页至少等0.3秒。KEY1是RTL名称，对应沿用052接线的丝印KEY2。SW[3:1]从000到111依次为d0至d7。

| 页 | 含义 | 正常预期 |
|---|---|---|
| d0 | S1识别 | 05465 |
| d1 | 32767个CTRL周期对应的基准周期数 | 约32767，允许±2 |
| d2 | 32767个MEM周期对应的基准周期数 | 约32767，允许±2 |
| d3 | 32767个PIXEL周期对应的基准周期数 | 约65014，允许±2 |
| d4 | 已捕获9999、65535、65536、499999的四位标志 | 00015 |
| d5 | 有效/锁定/复位/不一致/停钟状态 | 健康全就绪16639，位定义见下 |
| d6 | 首个停止结果的DUT低16位 | 41247 |
| d7 | 固定高位校准 | 65280 |

SW0=0不会切换时钟或停视频，只把部分页换为参考读数：P4为DUT高13位（正常7），P5为参考高13位（正常7），P6为参考低16位（正常41247）；其他页数值不变。请记录彩条是否出现，以及d1～d6；若d4/d5异常，再补P4～P6。正常后隔10秒复读d4/d5/d6，随后≥10分钟稳定并KEY1复现。失败也保留完整读数，不只反馈“黑屏”。

测量公式为 `源频率 ≈ 基准频率 × 32767 / 读数`。以板载基准50MHz计算，CTRL/MEM应50MHz、PIXEL应25.2MHz；它是相对测量，不是外部仪器校准的绝对频率。源端LFSR避免依赖CTRL宽加法；基准间隔计数仍为16位加一，不能把测量子系统自身无误当作前提。读数必须结合d5的valid/stale判断，旧有效值不能证明时钟仍在运行。

| d5位 | 含义 |
|---|---|
| 0、1、2 | CTRL、MEM、PIXEL测量已取得完整周期 |
| 3、4、5 | 网络PLL锁定、视频/音频PLL组合锁定、HDMI IP视频输入锁定（均同步到基准域） |
| 6、7 | CTRL复位已释放、冻结结果已捕获 |
| 8 | 首个计数DUT/参考不一致，置位为异常 |
| 9、10 | 武装后CTRL复位重现、网络PLL解锁，置位为异常 |
| 11、12、13 | CTRL、MEM、PIXEL事件超出65535基准周期窗口，置位表示停钟/过慢或测量未更新 |
| 14 | 复位监视已武装 |
| 15 | 固定0 |
