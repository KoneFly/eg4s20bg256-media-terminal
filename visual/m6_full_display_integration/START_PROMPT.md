## 1. 目标

在 **052 第四步主板树快照**上一次性补齐 M6 显示链的两块缺口，产出"**完整 M6 显示位**"：

```
副板 7175ECC3（FFT，不动）→ 帧快照（三银行，已有）
        ↓
【W2 pcb_frame_updater】→ T1/T2 真双口表（pcb_state_mem）→ S2 pcb_pixel_renderer
        ↑
【标签图链：SDRAM 载入 + 行区段表读取 → in_label 供给】
        ↓
     HDMI 单屏输出：PCB 线稿（环/走线/元件/芯片/音柱）
                + 状态驱动动态（生长/电流/脉冲/节点/彗星/音柱高度与峰值帽）
                + 底部常驻 128 柱
```

**不含**（明确边界）：TF 真音频（第五步，另排）、043 主线合体（终态另行）、粒子与柱顶连线（已裁）、W1（已出列）。

## 3. 工作项

### 3.1 方案评审（唯一中途 checkpoint：先出 1 页，规格方确认后实施）

必须包含：

- **标签图载入路径**：候选 = TF→SDRAM（裁剪复用 043/第五步资产，仅"读文件→写 SDRAM"窄路径）；或其他更简方案。给出选择理由；
- **资源预算**（全量：LUT/REG/ERAM9K/32K/DSP/PLL）——目标 **总占用 ≤90%**；**超预算即停、报告待裁定，不得静默裁规格**；
- **引脚冲突核查**：SDRAM/新增引脚 vs 现有网口/HDMI 的 `.adc` 分配（板上多外设共存，官方 lab_ex_6 为共存先例）；
- **行区段表读取链设计**：SDRAM 读仲裁（标签读 vs 其他访问）+ 行缓存 + `in_label` 供给，对齐显示扫描序与 `async_pixel_fifo` 同拍语义（S2 端口 `in_label`，见 `vendor/m6_s2/pcb_pixel_renderer.v`）。

### 3.2 W2 焊入

- 数据流：`v9_spectrum_snapshot`（三银行）→ **W2** → T1/T2（`pcb_state_mem` 真双口化）→ S2；
- 替换四步树内现有简易柱更新逻辑；W2 只经**冻结正式端口**交接；`frame_tick` 节拍语义与独立验证口径一致。

### 3.3 集成验证 + TD + 出位

- 集成台：W2 写口对拍（沿用独立黄金）+ T1/T2 表读写一致性 + S2 像素流完整性 + 标签流扫描序；
- 独立 TD：**0 违例**（Setup/Hold）；资源登记；告警如实 OPEN；
- 出 bit（登记 BURN_INDEX 由主人/浮浮酱走流程）。

### 3.4 上板验收（与主人配合）

判据：
1. 上电即见**完整 PCB 线稿**（环/走线/元件/芯片/音柱，无错位、无撕裂）；
2. 频谱输入下**动态可观察**：音柱起伏、峰值帽、走线电流、节点辉光、彗星；
3. 底部 128 柱随频谱动态；
4. 长时间运行稳定（≥10 分钟）。

## 4. 边界情况（必须防御）

- **标签图载入失败**（TF 缺失/校验不过）：明确告警落点（数码管/LED 码），不得静默黑屏；
- **SDRAM 读写竞争**：标签读取 vs 其他访问的仲裁与优先级定义；
- **帧快照异常**（epoch 跳变/副板重启）：W2 输入连续性的既有 epoch 机制延续；
- **静音输入**：画面全静态正确（线稿保持、动态归零、底部柱归零）。
