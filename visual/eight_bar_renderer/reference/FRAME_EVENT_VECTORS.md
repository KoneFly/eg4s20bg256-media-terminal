# 固定帧事件向量

用途：为V07—V10、V13提供预先给定的期望，不允许通过DUT内部状态生成判据。所有场景独立复位；完成复位同步和首次VS定位后，从F0开始编号。Fj指第j次指定场提交之后的有效画面。所有能量输入在建立时间之前稳定；表中的同沿按键同样在该采样沿之前建立，不在采样沿临时赋值。

统一几何：8根柱的x区间使用 `eight_bars_geometry.json`；下端419。以下均给8路相同能量，所以各柱上端相同。top为空表示全黑；配色0/1/2使用固定色表。shift=0，除非表格另有指定。每个完整帧仍检查307200个valid像素，不能用全程invalid冒充全黑。

## A：帧内输入改变（V07）

| 帧 | 提交时8路输入 | 帧内刺激 | 本帧固定期望 |
|---|---:|---|---|
| F0 | 0 | 在外部坐标(100,200)所在周期开始前改为255，保持至F1 | 全黑，top为空 |
| F1 | 255 | 无 | top=165，palette0，着色97920像素 |

F0刺激后直到帧结束仍逐像素检查黑色，而不是仅看刺激前部分。

## B：冻结、持续改变输入、同沿解冻（V08）

| 帧 | 提交时8路输入 | 按键刺激 | 本帧固定期望 |
|---|---:|---|---|
| F0 | 128 | 本帧有效区KEY1一次 | top=292，palette0，着色49152像素 |
| F1 | 255 | 无 | top=292，palette0，着色49152像素 |
| F2 | 0 | 无 | top=292，palette0，着色49152像素 |
| F3 | 255 | 与F3提交同沿KEY1一次 | top=292，palette0，着色49152像素 |
| F4 | 64 | 无 | top=356，palette0，着色24576像素 |

固定公开输出探针：F0—F3的(64,291)=0000，(64,292)=FEE0；F4的(64,355)=0000，(64,356)=FEE0。实际TB应整帧检查，探针仅帮助定位错误。F3不能提前变高或解冻。

## C：组合键、KEY2优先、保留位（V09）

| 帧 | 提交时8路输入 | 前序按键刺激 | 本帧固定期望 |
|---|---:|---|---|
| F0 | 128 | 无 | top=292，palette0 |
| F1 | 255 | F0有效区KEY0与KEY1同拍一次 | top=292，palette1 |
| F2 | 64 | F1有效区KEY0/KEY1/KEY2三键同拍一次 | top=356，palette0 |
| F3 | 64 | F2有效区KEY3一次，sw_level=12并保持 | top=356，palette0；高两位不得改变幅度 |

KEY2使pending恢复默认，不能被同拍KEY0递增覆盖。冻结只控制能量快照；F1颜色仍应变化。

## D：VS相邻边沿（V10）

以下三行是三个独立子场景，均在F0锁存全255、palette0。相对于F1提交沿C，C−1/C/C+1均指像素时钟上升沿，不是浏览器帧。

| KEY0采样时刻（仅一次） | F1固定颜色 | F2固定颜色 |
|---|---|---|
| C−1 | palette1 | palette1 |
| C | palette0 | palette1 |
| C+1 | palette0 | palette1 |

三场景所有帧top=165。所有KEY0相关检查必须在可见画面判断，不能仅确认pending寄存器。

开关另做三个独立子场景，F0全255且shift0，在C−1/C/C+1分别开始采样到sw_level=1并保持：

| sw_level首次采样为1 | F1固定top/着色数 | F2固定top/着色数 |
|---|---|---|
| C−1 | 293 / 48768 | 293 / 48768 |
| C | 293 / 48768 | 293 / 48768 |
| C+1 | 165 / 97920 | 293 / 48768 |

开关直接在提交沿采样，因此与KEY0的pending语义不同。

## E：行消隐不提交（V13）

F0提交全255、palette0、shift0。在F0第100个有效行之后的行消隐，KEY0一次，sw_level改为1并保持。F0所有有效像素仍应为top165、palette0；F1应为top293、palette1。不能只检查第一行颜色，也不能只比较参数寄存器。

## 使用边界

这些是按候选接口手工推导的固定刺激/期望，尚未对RTL执行，不构成时序仿真PASS。计数由矩形面积手算：8×48×128=49152、8×48×64=24576、8×48×127=48768。几何和色表沿用既有固定数据，不另写DUT同构的逐拍参考算法。
