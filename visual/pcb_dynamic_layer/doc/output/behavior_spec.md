# pcb_dynamic_layer W2 当前行为规格

> 最后核对日期：2026-10-04  
> 维护者：pcb_dynamic_layer 执行方  
> 当前范围：W2 多周期版；W1 已归档出列。

正式口、字段及配置以 doc/brief/INTERFACE_SPEC.md 为准；当前面积/时序及证据唯一入口为 W2_MULTICYCLE_REPORT.md / sim/td_result_mc.json。

复位后写入集中 bank 的 2048 个词，包括原 startF 初值，排空后进入 ready。初始化期间 busy=1，正式写口关闭。frame_ready=!busy && ack_sync==state_commit_toggle；仅 ready 的单拍 tick 锁存完整频谱与配置。非 ready 请求拒绝并置 sticky err_code=1。

配置地址 0..7 保持原名称/默认/饱和范围；共享限幅实现显式补零高位。粒子地址 8..10 退役，11/12/非法地址不改变本包固定基线。配置与 tick 同拍用旧值，busy 时写入只影响后续帧；这些锁存行为已由补充外部接口用例对拍。

保留段能量/正谱通量、起音/节拍、四个环上彗星、走线生长/flow/三槽脉冲、元件、节点及 128 音柱 H/Peak/peakHold。无外侧粒子、LFSR 或 P 状态。内部多周期化不改变更新的模型顺序、整数取整、饱和及弱槽/空槽选择。

谱索引与谱值分拍注册；同构 rise/fall 共用 9bit 减法器，必要乘法共用一个 DSP，生长比值沿用串行除法。trace 共用读改写缓冲，node/bar 共用词记录缓冲。集中 bank 地址规划与同步一拍读口保持 V2。谱通量平均值使用其可达范围内的完整 12bit 数据，不截掉有效状态。

发布仍为 T1 128 地址×4 lane=512 写，地址 70..127 清零；随后 T2 0..139 共 140 写。最后 T2 写排空后 DRAIN，再单次翻转 commit、单拍 done。ack 返回并经 2FF 同步前不能接受下一帧。更新中或 T2 发布中复位撤销未完成快照，已测试复位重入。

内部算术增加等待拍；未要求保持旧更新周期。当前已测默认最高 18276 拍，配置补充最高 19703 拍；完整数字和门禁见测量报告，不将已测最大值解释成形式上界。

W1 正式接口、行桶及像素输出整体出列。snapshot_ack_toggle 仍由外部快照接收方提供，独立 TB 模拟该接收方，本轮不实现或集成它。解析式绘制仅为二期候选。

状态更新、存储、黄金与测试各自承担明确职责；通过共享算术及记录缓冲减少重复，实现只覆盖当前授权范围。系统集成与板级验收保持未执行。
