# pcb_dynamic_layer 当前行为规格

> 日期：2026-10-04  
> 状态：W2 默认参数功能版；资源门禁失败。W1 未实现。本文件不是验收结论。

`pcb_frame_updater` 使用冻结正式端口。复位后执行 128 拍状态 RAM 初始化，期间 `busy=1`；对外 T1/T2/P 写口关闭。内部几何、startF、LFSR 与配置保留模型定义的初始值，不能解释成所有内部位均为零。

`frame_ready` 为 `!busy && ack_sync==state_commit_toggle`。只有 ready 时的单拍 tick 被接受，频谱 1024bit 与全部配置在该拍锁存。busy 或未收到同步 ack 时到达的 tick 被拒绝，`err_valid/err_code=1` 保持到复位。配置写口独立更新下一帧配置；越界地址忽略、值按任务范围饱和。配置与 tick 同拍时使用写入前的配置；配置边界矩阵尚未验证。

每帧按模型顺序处理段聚合、正谱通量、起音、节拍与彗星，再处理走线生长、flow、3 槽脉冲、元件、节点、柱高/峰值/冷却与粒子。谱读取共用一个选择器；唯一注册 16×16 乘法器复用；生长比值由 16 拍逐位除法得到。constant coefficients 使用移位加法，8bit 乘法辅助函数使用移位累加，不引入新的 DSP。

内部状态仍使用六类同步 RAM：trace 128×128、startF 128×16、node/bar 各 128×32、particle 128×80、history 128×168。节点 pulse 的空槽判据为 peak==0；无空槽时选最远位置。粒子从 pHead 起寻找第一个 life==0 的槽；全满时替换 pHead。坐标先按 Q4 积分，再算术右移得到历史像素坐标；P 保留 x11/y10 有符号历史点，屏外历史点不先清零。

对外快照固定按以下序列发布：

1. T1：128 地址，每地址 lane 0..3，共 512 写；地址 70..127 为零。
2. T2：地址 0..139，共 140 写；字节均显式限到 8bit，core=256 折为零。
3. P：地址 0..1535，共 1536 写；每粒子 12 个低字在先的 16bit 字。
4. 最后写完成后经 DRAIN 再翻转一次 commit，并产生单拍 frame_done。

等待 W1 的 ack 期间不产生新的写入；两拍同步 ack 后才能接受下一帧。复位立即撤销写使能和 commit，不发布未完成快照。reset/commit 的跨域系统集成仍需要后续 W1 联合验证。

W1 的接口与已确认 6144×24bit 行区段格式记录在 `doc/brief/INTERFACE_SPEC.md`，仅有独立黄金审计；没有 W1 DUT、647 拍像素延迟或合体结果。单帧无命中也要求 overlay_valid 随输入延迟，hit 单独表示覆盖命中。

资源现状与下一步见 `RESOURCE_REFACTOR_REPORT.md`。按单一职责划分，W2 仅产出状态、黄金脚本仅提供参考、TB 仅检查真实写口；保持接口与画面规格，未为面积目标缩减粒子、历史点或线宽。
