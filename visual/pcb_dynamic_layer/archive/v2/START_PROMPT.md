## 二、W1 — 覆盖层光栅化（`pcb_particle_overlay`）

- **输入**：状态表读口（粒子 8 点历史位置、音柱峰值/柱顶、彗星位置 —— 字段与 task_045 契约及 W2 约定一致）；
- **处理**：每帧从状态表取几何 → **按行分桶** → 在像素流中**逐行光栅化**短线段
  （粒子轨迹连线 + 柱顶连线/峰值帽，三段绘制按 SKETCH §1 冻结视觉）；
- **输出**：覆盖层像素（颜色/使能），供 S6 的合成级与 S2 输出叠加；
- **硬约束**：与 S2 输出同像素时钟域、同帧节拍（flush 语义对齐）；输出序即扫描序（不得乱序）。

## 三、W2 — 帧更新器（`pcb_frame_updater`）

- **输入**：每帧 128 路频谱（8bit，语义见 SKETCH §3.1）+ 帧节拍（frame_tick 或自派生）；
- **处理**：按 SKETCH §3 全部动力学实现（§3.2 八段聚合与起音 → §3.3 走线生长 → §3.4 持续电流
  → §3.5 起音脉冲 → §3.6 节点与片内低频表 → §3.7 音柱与粒子 → §3.8 环上电流彗星）；
- **输出**：**状态表写口**（地址/数据/写使能）—— 写入 W1 与 task_045 渲染器共同读取的同一张表；
  表容量与条目按 task_045 契约与 SKETCH §3 字段清单核定；
- **硬约束**：全整数（SKETCH §3 已定）；参数全部寄存器化（§6，含与冻结值一致的默认值）；
  与 `st_*` 契约**逐字对齐**，不确定处先向协调方确认。
