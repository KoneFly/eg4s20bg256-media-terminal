## W2

复位后依次写入集中 RAM 的 2048 个 16bit 字，包含模型定义的 startF 初始值，再经初始化排空进入 ready；不能将全部状态理解成零。初始化期间 busy 为 1，对外写使能关闭。状态 bank 地址与记录形状见 V2 接口文档，无粒子状态、历史或 P bank。

`frame_ready = !busy && ack_sync==state_commit_toggle`。ready 时接受单拍 tick，并锁存 1024bit 频谱和配置；busy 或未同步 ack 的额外请求被拒绝，置 sticky `err_valid/err_code=1`。配置地址 0..7 保持原默认值与范围；8..10 退役且写入忽略。11/12 在本包固定基线下不改变可观察结果，边界矩阵尚未执行。配置与 tick 同拍使用写入前值。

更新保留段聚合、正谱通量、起音、节拍、环上彗星、走线生长/flow/三槽脉冲、元件、节点、音柱 H/Peak/peakHold。串行同步词口统一访问状态；注册乘法器复用，生长比值使用逐位除法，取整与饱和不改。已批准的弹射粒子触发、LFSR、速度、积分、寿命、槽回收和历史路径全部移除。

发布顺序：

1. T1：128 地址、每地址 lane 0..3，共 512 写；地址 70..127 清零。
2. T2：地址 0..139，共 140 写；字段字序与 task_045 packState 保持一致。
3. 共 652 写结束后经 DRAIN，commit 翻转一次、frame_done 单拍。
4. 等待接收侧返回 ack，经 2FF 同步后允许下一帧。

复位撤销写使能和提交，不发布未完成快照；更新中/T2 发布中复位重入已有真实写口测试。没有 P 写序或 P 末拍提交条件。

## W1

W1 对 commit 经 2FF 同步，预取 T2 64..127 及 137，缓存 128 柱高与 ovK 后返回 ack。ack 表示快照读取结束，**不表示行池构建完成**；构建完成由内部 publish_pulse 标识，未新增正式端口。

只构建 127 条相邻柱顶连线，首尾不闭环。半径为 `193+((barH*34)>>8)`，坐标按既有 ex/ey 定点公式计算；任一相邻柱的像素高度非零才绘制。整数 Bresenham 包含端点，先裁剪基础像素再 3×3 膨胀，luma=170。峰值帽、音柱和环上彗星仍由保留状态及既有 S2 路径处理，不在 W1 重绘。

几何、辅助链表和行池写入只在 in_valid=0 时推进。最终正式池保持 `6144×24bit`，行目录 base13/count10；每条记录 x0/length_minus_one/luma，长段最多 64px。有效输入期只消费同步预取 FIFO，命中颜色由 in_ridx 调色，alpha=(170*ovK)>>8；未命中颜色/alpha 为零，hit 独立于 alpha 是否为零。

像素包先注册，再经过循环延迟 RAM，自然时钟延迟固定为 647 拍，包含 valid/hit/RGB565/alpha 和内部 SOF/EOL。无效输入也占自然时钟拍，不压缩气泡。溢出锁存 bucket_overflow_sticky，不静默绕写。

当前单活动行池只验证了完整发布后的输入帧与已完成快照间切换。发布未完成即进入有效期的原子性未验证，且 bar_alternating 构建超出冻结消隐期限；这两个边界保持失败/未验证记录，不能视为连续系统实现已通过。

## 验证与实现原则

黄金只读原模型/独立几何，TB 检查正式口，DUT 内部 publish_pulse 仅用于观测阶段完成，SOF/EOL 只用于延迟监测。状态更新、RAM 词口、区段存储和对拍各自职责明确；统一地址规划与算术复用减少重复。保持已授权范围，不通过缩减冻结语义或修改黄金取得预算通过。
