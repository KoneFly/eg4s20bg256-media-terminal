# EG4S20BG256 FPGA 多媒体终端（基线 / 迭代归档集）

本仓库保存**基线代码**与**有重大改动的版本代码**（改动前后各一份，作版本迭代便于 diff）。

## 纳入 / 不纳入

- ✅ **纳入**：**冻结基线**、**重大迭代版本**（**即使未出 bit，也以纯代码快照纳入**，并在索引中标注状态）
- ⛔ **不纳入**：**项目文档**（本地维护）、官方 / 开源资料、个人素材、**加密厂商 IP 源文件**、临时编译输出、测试黄金大文件、失败 bit

## 怎么读

先读 [DELIVERY_INDEX.md](DELIVERY_INDEX.md) —— 它记录每个快照的**板上 / 仿真状态**与**证据边界**；`SHA256SUMS.txt` 校验本仓库文件。

器件：安路 EG4S20BG256 / HX4S20C。工具版本、IP 依赖与复现条件以各快照的 TD 报告、约束及源清单为准。加密厂商 IP 源文件未复制，需在本地合法安装的安路工具链中解析。
