## 1. 作品简介

本作品以安路 EG4S20BG256 为平台，单板即构成完整多媒体终端，双板联用形成现场采集与画面回放的对比闭环，全部算法在 FPGA 内实现，不含任何处理器。

**主板**从 TF 卡读取 BMP 图片、V29 视频与 WAV 音频，经原生四线 SD 读卡、FAT32 只读解析、片上 SDRAM 帧缓冲与最近邻重采样后，输出 640×480 HDMI 视频与 48 kHz I2S 音频；支持八槽双层图片墙预览与全屏大图切换、三级分辨率缩放、淡入淡出与擦除与幕布等可开关转场、1 至 60 秒可调自动轮播与仪表盘显示，换卡后按键即可重载生效。

**副板**以 I2S 接收四路数字麦克风，三路均值融合、另一路作误差检测，经 150 Hz 至 2 kHz 四节带阻滤波后执行 4096 点 FFT，将滤波前后两条同索引频谱回传主板与画面同屏显示；同一信号按 I2S 双槽送外接功放，实现处理前后的听感对比。在此基础上，系统还能对单一频率的稳态噪声做自适应反相相消，在扬声器前方数厘米处生成反相信号，形成电域整形与声学相消两级处理。

板间以一根 HDMI 线缆承载串行信号，**不使用 HDMI 协议**。作品以对比为核心：一是现场声与回放声并置，二是处理前后的频谱与听感同显，适合设备噪声治理、展陈与巡检等场合。

## 2. 硬件与实现指标

| 项 | 主板 F3.5 | 副板 R69 |
|---|---|---|
| 顶层模块 | `t073_master_top` | `slave_demo_physical_wrapper` |
| 器件 | EG4S20BG256（HX4S20C） | EG4S20BG256（HX4S20C） |
| RTL 规模 | 64 个 `.v` + 3 个头文件 | 41 个 `.v` + 7 个头文件 |
| **PLB（门禁 2450）** | **2390 / 2450** | **2431 / 2450** |
| Setup / Hold WNS | 3.750 / 0.230 ns，零违例 | 0.736 / 0.042 ns，零违例 |
| BRAM9K / 32K / DSP | 59 / 14 / 5 | 25 / 12 / 13 |
| 位流 SHA256 | `250e679b60af0246fe9be7d56c25e96a0bb58fa0d8d3834424a64e9dd2cc4661` | `55d30f56cc77801f5b952b32eb1feb2627fa75600d624fccb572f9f8f9911d4a` |

**关键时钟与规格**

- HDMI 640×480@60，像素时钟 **25.2 MHz**，串行 **126 MHz**（每像素 10 bit TMDS）
- I2S 音频 **48.076923 kHz**（锁定 LRCK，非 48000）
- 片上 SDRAM 8 MB，划分**七页**：视频三页、图片两页、图墙两页；四 bank 开页流水
- SD 原生四线，开放式多块读，块池 8 槽，停钟流控，高速模式 **50 MHz**
- 器件资源：19600 LUT / 19600 FF / 29 DSP / 64×RAM9K / 16×RAM32K

## 3. 功能一览

| 环节 | 做法 |
|---|---|
| 读卡 | 原生四线 SD，开放式多块读，块池 8 槽，停钟流控；高速模式 50 MHz |
| 文件系统 | FAT32 只读，8.3 名，extent 索引；图片与音乐两个上下文分时共用读卡 |
| 帧存储 | 片上 SDRAM 七页，四 bank 开页流水，写/读经仲裁 |
| 显示 | 每帧描述字驱动两层 DMA，帧边界原子切换；转场引擎逐像素一拍 |
| 图片 | 任意尺寸等比最近邻适配；÷1/÷2/÷4 三级采样由行地址与水平保持实现 |
| 图墙 | 读图时顺带写 ÷2 缩略图，显示时线性读，不额外占用片上 RAM |
| 音频 | 视频伴音、WAV、测试音共用一个音频桥；桥后 PCM 同时供板间链路 |
| 板间 | 自有串行协议，一根线缆承载主→副 PCM 与副→主两路频谱 |
| 副板采集 | 四路 I2S 数字麦克风：一路误差、一路参考、其余参与均值 |
| 副板处理 | 4 节二阶节滤波 → 4096 点 FFT（仅观测）→ 128 tap 声路模型 → 自适应系数更新 → I2S 反相输出 |
| 副板保护 | 增声检测、静音核查、等待源与首错快照；不因听感绕过保护 |

## 5. 复现

完整步骤见 [`deliveries/073_master_f35_slave_r69/README.md`](deliveries/073_master_f35_slave_r69/README.md)，要点：

| 用途 | 环境 |
|---|---|
| 综合 / 布局 / 布线 / 出位 | 安路 TD 6.2（命令行 `td_commands_prompt.exe`），器件库 `eagle_s20.db` |
| 仿真 | WSL（Ubuntu）+ Verilator 5.x + g++ |
| 素材与脚本 | Python 3.10+，`numpy`、`scipy`；`ffmpeg` 在 PATH 中 |
| 串口 | 副板诊断用 CH340 类 USB-UART，1 Mbps 8N1 |

```bash
# 主板位流
cd deliveries/073_master_f35_slave_r69/master_f35/td_run && bash run_b1.sh

# 副板位流
cd deliveries/073_master_f35_slave_r69/slave_r69/td_run
td_commands_prompt.exe synth.tcl && td_commands_prompt.exe place.tcl && td_commands_prompt.exe route.tcl
echo ok > release_authorization.permit && td_commands_prompt.exe complete_bitgen.tcl
```

> ⚠️ **厂商加密 IP 不在本仓库内**。`master_f35/vendor/` 下的 HDMI 1.4b 发送器为加密 `.enc.v`，
> 不可读、不可改，仅随工程编译；构建前需在本机合法安装的安路工具链中取得该文件。

## 6. 口径与边界（诚实声明）

本作品的技术结论均区分「已确认 / 推算 / 未确认」，仓库与文档中不夸大实测：

| 项 | 表述 |
|---|---|
| 消除噪声的方式 | **电域整形 + 声学相消**（不称「降噪」「屏蔽外界噪声」） |
| 转场类型 | 只有**淡入淡出 / 擦除 / 幕布**（不存在「模糊化转场」） |
| 换卡重载 | 重载后音乐停止，需手动从 WAV1 曲头重播（不称「音乐热重载续播」） |
| ANC 效果 | **实测约 6 dB，最佳约 16 dB**；存在频率失锁导致的不稳定（不称「稳定 16 dB」） |
| 视频播放 | **SD 不是唯一瓶颈，SDRAM 写通路才是**（不称「带宽够就能放视频」） |
| 板间链路 | 一根 HDMI 线缆承载**自有串行协议**，不使用 HDMI 协议 |
