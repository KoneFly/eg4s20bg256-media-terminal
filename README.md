# EG4S20BG256 FPGA 多媒体播放项目（归档交付集）

本仓库只保存已确认上板归档交付的源代码、约束、bit及关键TD报告。全量开发工作区、执行过程日志、官方资料、素材、未验收任务和临时仿真产物不在此仓库。

开始前阅读 [DELIVERY_INDEX.md](DELIVERY_INDEX.md)。该索引记录每个快照的板上状态与证据边界。SHA256SUMS.txt校验本仓库文件。

器件：安路 EG4S20BG256 / HX4S20C。工具版本、IP依赖和复现条件以各快照的TD报告、约束及源清单为准。加密厂商IP源文件未复制，需在本地合法安装的安路工具链中解析。
